# Windows 验收清单（在真实 Windows 电脑上手工跑一遍）

> 为什么需要这份清单：开发和测试都在 Mac 上做，**没有在任何 Windows 电脑上运行过**。Windows 安装包、文字识别脚本（ocr.ps1）、中文字体、关窗退出等只做了静态检查，需要你在一台真实的 Windows 10 / 11 电脑上走一遍。
> 用时：约 40 分钟（其中第 6 项要用你自己的 AI 密钥，会产生少量费用，可以只做前半）。
> 每一项写了「怎么做」和「应该看到什么」。**任何一项和预期不一致，请截图并记下是哪一项**，连同「设置 → 关于」里的版本信息一起发回。
> 需要的文件：安装包 EnglishExamWorkbench-1.1.0-win-x64-setup.exe 和免安装版 EnglishExamWorkbench-1.1.0-win-x64-portable.exe；试卷样本是项目 samples 文件夹里的 g4-2025.pdf、g4-2026.pdf 和 g4-2025-page1.png——**验收的电脑上没有项目文件夹，请提供软件的人把这三个文件和安装包一起发给你**（也可以改用你自己的试卷）。

## 1. 安装与 SmartScreen

**怎么做：**

1. 双击 setup.exe。
2. 如果出现蓝色的「Windows 已保护你的电脑」，点「更多信息」，再点「仍要运行」。
3. 向导会问「为谁安装」：保持默认的「仅为我」，点「下一步」。再选一个安装位置（可以改），完成安装。

**应该看到：** 向导是中文界面；有「为谁安装」这一页，选「仅为我」不要求管理员密码（选「所有用户」才会要求）；能改安装目录，默认目录是 C:\Users\你的用户名\AppData\Local\Programs\EnglishExamWorkbench（**请核对目录名，记下实际是什么**）；向导里没有「创建桌面快捷方式」的勾选项，但装完后桌面和开始菜单里**自动**出现「英语校考分析工作台」快捷方式，图标是蓝紫色底、白色试卷加三根柱状图（占位图标）。

## 2. 首次启动、图标、版本和数据位置

**怎么做：** 从桌面快捷方式打开软件，进入「设置」，往下找到「关于」卡片。

**应该看到：**

- 窗口正常打开，界面是中文，没有乱码和方块字；试卷库页面中央有拖拽区；有标题为「开始使用：三步就能出第一份分析」的三步卡片。
- 任务栏上的图标是上面那个蓝紫色图标，不是默认的 Electron 原子图标。
- **任务栏标识：** 在任务栏的图标上点右键选「固定到任务栏」，关闭软件，再点任务栏上固定的这个图标启动：任务栏上应该只有**一个**图标（不是固定的一个加运行中的另一个）；任务管理器「进程」页里应用名显示为「英语校考分析工作台」。如果出现两个图标，说明任务栏分组标识（AppUserModelID）和快捷方式对不上，请截图。
- 「关于」里：版本 1.1.0；系统 win32；数据库版本 v10；数据目录是 C:\Users\你的用户名\AppData\Roaming\english-exam-workbench\workbench-data。
- 在资源管理器地址栏输入 %APPDATA%\english-exam-workbench 回车，能看到 workbench-data 文件夹，里面有 db.sqlite 和 files 文件夹。

## 3. 文字型 PDF 导入（不用 OCR）

**怎么做：** 把 g4-2025.pdf 拖进试卷库窗口。

**应该看到：** 几秒内这份卷子的状态变成「已提取」（没配 AI 时不会自动解析）。点进卷子详情：页面图清晰，文字叠加层和页面上的字对得上；中文没有乱码。

## 4. 图片导入：OCR 与中文语言包

**先看状态：** 「设置」页的「文字识别（OCR）」卡片。三种情况：

- 显示「可用」和「Windows OCR（zh-Hans-CN）」：已经有中文 OCR，直接做下面的导入。
- 显示「可用」但写着「当前使用 en-US……中文可能识别不全」：只有英文引擎。先导入试试，按「应该看到」里的第二种情况核对；再按安装指南第四部分装中文语言包，重启软件再做一遍。
- 显示「不可用」：写明了原因。按「应该看到」里的第三种情况核对。

**怎么做：** 把 g4-2025-page1.png 拖进窗口，进入这份卷子的详情页。

**应该看到：**

- 有中文 OCR：几秒到十几秒内状态变成「已提取」，详情页的文字叠加层和页面文字位置贴合，中文识别基本正确，汉字之间没有多余的空格。
- 只有英文引擎：试卷上有黄色提示「OCR 使用 en-US 引擎，中文可能识别不全……」，英文部分能识别，中文部分可能缺失。**不能是识别出一堆乱码却没有任何提示。**
- 没有 OCR：这份卷子在试卷库里标「OCR 失败」（或「已提取·有提示」），详情页这一页上方有红色提示「这一页的 OCR 没有成功：……」并写出原因（比如「没有安装 OCR 语言包」；系统根本没有 OCR 功能时则是「待 OCR（当前平台不支持）」）；设置页的状态是「不可用」。**不能显示成功。**

**可选的底层检查（需要中文 OCR 才有意义）：** 在桌面快捷方式上点右键，选「打开文件所在的位置」，就能找到安装目录，里面有 resources 文件夹，再往里是 native 文件夹，里面有 windows 文件夹和 ocr.ps1 文件。按住 Shift 点右键选「复制文件地址」，得到它的完整路径。打开 PowerShell，把下面两行里的两处路径换成你的（样本图片的路径也要换），分别运行：

```
powershell -NoProfile -ExecutionPolicy Bypass -File "ocr.ps1 的完整路径" -Check
powershell -NoProfile -ExecutionPolicy Bypass -File "ocr.ps1 的完整路径" "g4-2025-page1.png 的完整路径"
```

第一行应输出类似 {"lang":"zh-Hans-CN"}；第二行应只输出一大段 JSON（不夹杂其他文字），里面有 30 多条以上的 lines，中文没有乱码。

## 5. 示例数据和看板

**怎么做：** 「设置」页的「示例数据」卡片 →「加载示例数据」。等几十秒后点左边的「总览」和「分析看板」。

**应该看到：** 页面顶部有横幅「当前看的是示例数据（内置的合成演示卷，不是任何真实考情）」；总览有 12 份试卷的数字卡片；分析看板的知识点方块图、出现率柱状图、同比四栏都有内容；点击一个知识点能展开题目截图卡片，截图里的中文试卷文字清晰（示例卷面是软件自己渲染的，用的是 Windows 上的中文字体，如果这里是方块字，说明字体回退有问题，请截图）。测试完毕后回到「设置」页的「示例数据」卡片，点「清除示例数据」。

## 6. 配置 AI、解析一份卷子

> 这一项会调用你自己的 AI 服务，按用量收费（一份卷子通常是几分钱到几毛钱，以服务商为准）。

**怎么做：**

1. 「设置」→「AI 服务」，选 DeepSeek（或你有密钥的其他服务商），填 API Key，点「保存」，再点「测试连接」。
2. 回到试卷库，把 g4-2025.pdf 拖进去（如果第 3 项已经导入过，在处理队列里点这份卷子的「重试」）。

> 提示：如果在「AI 服务」里填了「视觉模型」，识别失败或质量差的扫描页会把**页面图片**发给 AI 服务商；这一项只用文字型 PDF，可以不填视觉模型。

**应该看到：** 「测试连接」显示「连接成功」；解析过程中队列页有进度；完成后卷子进入「待审核」，审核页左边有题目列表（二三十道题），中间的页面上有框住当前题目的高亮框，右边有知识点标注。点「确认」后卷子变成「已完成」，总览的数字更新。重新启动软件后「设置 → AI 服务」里仍显示「已设置」（密钥由 Windows 的 DPAPI 加密保存）。

## 7. 导出 PDF 报告：中文字体

**怎么做：** 先保证看板里有数据（用第 5 项的示例数据，或者第 6 项解析好的卷子）。进入「AI 报告」页，点「生成报告」，等它完成；然后点「导出 PDF」，保存到桌面，用 PDF 阅读器打开。再点「导出 Markdown」，打开保存下来的 .md 和同名文件夹。

**应该看到：** PDF 里的中文全部正常显示（**没有方块字、没有问号**），标题、表格、引用的试卷截图都在，页脚有页码。Markdown 同名文件夹里有真实的截图 PNG。这一项是最容易在 Windows 上出问题的：软件指定的字体顺序是「微软雅黑」等，如果显示异常请截图并告诉我你的 Windows 版本和语言。

## 8. 数据包导出与导入

**怎么做：** 「设置」页的「数据包（换电脑 / 备份）」卡片 →「导出数据包…」，保存到桌面。然后点「导入数据包…」选这个文件，选「合并」，点「开始导入」。

**应该看到：** 导出完成提示里有试卷数、题数和文件大小；导入前的摘要写明「数据包里有 N 份本机已经有了」；合并之后试卷数不变（因为都是同一批）。数据包文件大小合理，用解压软件打开能看到 manifest.json、db.sqlite 和 files 文件夹。

## 9. 更改数据目录并重启

**怎么做：** 「设置」页的「数据存储」卡片 →「更改数据目录…」，在 D 盘（或桌面）新建一个空文件夹并选中，弹窗里会写「这是一个空文件夹」，点「复制数据并切换」。完成后点「立即重启」。

**应该看到：** 迁移有进度，完成后弹出「需要重启才能使用新的数据目录」的框，在重启之前页面上其他操作被拦住；点「立即重启」后软件自动重新打开，数据都在，「设置 → 数据存储」显示的是新目录；旧目录里的数据没有被删除。最后可以点「恢复默认位置」改回去（再重启一次）。

## 10. 关闭窗口后进程退出

**怎么做：** 点窗口右上角的 X 关闭软件。打开任务管理器（Ctrl + Shift + Esc），在「详细信息」页里找 EnglishExamWorkbench.exe。

**应该看到：** 关闭窗口后几秒内，所有 EnglishExamWorkbench.exe 进程都消失了（软件在 Windows 上关窗就是退出）。如果还剩一个后台进程，说明隐藏的渲染窗口没有被清理，请记下来。

## 11. 卸载后数据还在，重装后接得上

**怎么做：**

1. 「设置」→「应用」→「已安装的应用」（Windows 10 里叫「应用和功能」），找到「英语校考分析工作台」，点「卸载」。
2. 卸载完成后打开 %APPDATA%\english-exam-workbench。
3. 重新运行 setup.exe 安装，打开软件。

**应该看到：** 卸载过程是中文的；卸载之后 workbench-data 文件夹（你的试卷和数据库）**还在**；重新安装后打开，试卷库里还是原来的数据。

## 12. 免安装版

**怎么做：** 先关闭已经打开的软件。把 portable.exe 放到桌面，双击运行（第一次同样有 SmartScreen 提示）。

**应该看到：** 等几秒后窗口打开，界面和安装版一样；「设置 → 关于」里的数据目录和安装版是同一个位置（所以刚才的数据都在）；关闭窗口后进程退出。
