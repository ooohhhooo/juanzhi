# Windows 上安装「中文文字识别」（OCR）

卷知读图片、扫描件、手机拍的照片时，要靠 Windows 自带的文字识别引擎把字读出来。**Windows 默认只带英文的识别引擎，中文要自己装一次**；不装，中文会被读成乱码，AI 拆题就会不准。

只装一次，之后一直有效。文字型 PDF 和 Word 文件不需要它（卷知直接读里面的文字）。

> 提示：下面第一种方法（点设置）最稳，建议先试。第二种（一行命令）更快，适合有管理员权限、或要给很多台电脑装的人。

卷知会直接向系统要「简体中文（zh-Hans-CN）」的识别引擎，只要中文 OCR 功能装上了就能用，**不要求**把中文加进 Windows 的首选语言列表（所以方法二的一行命令也够用）。这一点还没有在真机上逐一确认；如果装完后设置里仍只显示英文，请再用方法一把中文语言加进去。

## 开始之前

- 电脑要**联网**（要从微软下载，大约几十 MB，几分钟）。
- 公司 / 学校的电脑可能被管理员限制了下载语言功能，装不上时请联系管理员，或者改用卷知里的「视觉模型」读图（见文末）。
- 不需要把 Windows 的显示语言改成中文，也不需要换输入法。

## 方法一：在「设置」里点（Windows 11）

1. 点开始菜单 → **设置** → 左边选 **时间和语言** → **语言和区域**。
2. 在「首选语言」旁边点 **添加语言**。
3. 搜索「中文」，选 **中文（简体，中国）**，点 **下一步**。
4. 在可选的语言功能里，确认勾选 **光学字符识别**（OCR）。其他的（语音、手写、基本键入）可以勾也可以不勾。
5. **取消勾选「设置为我的 Windows 显示语言」**（如果你想保持现在的界面语言不变），点 **安装**。
6. 等右边显示「已安装」。回到卷知，**关掉再重新打开**。

## 方法一：在「设置」里点（Windows 10）

1. 点开始菜单 → **设置**（齿轮）→ **时间和语言** → 左边选 **语言**。
2. 点 **添加首选的语言**（有的版本写「添加语言」）。
3. 选 **中文(中华人民共和国)** 即「中文（简体）」，点 **下一步**。
4. 在「可选的语言功能」里确认勾选 **光学字符识别**（以及「基本键入」可以一起勾上），**取消勾选「设置为我的 Windows 显示语言」**，点 **安装**。
5. 等它下载完（语言列表里那一项不再转圈）。回到卷知，**关掉再重新打开**。

## 方法二：管理员 PowerShell 一行命令

1. 在开始菜单搜索 **PowerShell**，在结果上点右键，选 **以管理员身份运行**，在弹窗里点「是」。
2. 复制下面这一整行，粘贴进去，按回车：

```powershell
Get-WindowsCapability -Online | Where-Object Name -like 'Language.OCR~~~zh-CN~*' | Add-WindowsCapability -Online
```

3. 等它跑完。成功时会显示 `Online : True` 之类的结果，`RestartNeeded : False`（不需要重启）。
4. 想确认装上了，再运行：

```powershell
Get-WindowsCapability -Online | Where-Object Name -like 'Language.OCR*' | Format-Table Name, State -AutoSize
```

看到 `Language.OCR~~~zh-CN~0.0.1.0` 后面的 State 是 `Installed` 就对了。

> 说明：这一行就是卷知自动测试（GitHub Actions 的 Windows 机器）里用的命令，但**还没有在每一种 Windows 版本和每一种企业环境里逐一验证**。如果提示「找不到」「0x800f0954」「访问被拒绝」等，请改用方法一，或把完整的报错文字发到反馈里。

## 怎么确认卷知能用了

1. 重新打开卷知，进入 **设置**，点开最下面的 **管理员设置**。
2. 找到 **文字识别（OCR）** 这一栏：状态应显示 **可用**，说明里写着 **zh-Hans-CN**（中文）。如果还是只有英文，点右边的 **重新检测**；还不行就重启电脑再试。
3. 以后导入图片 / 扫描件时，如果这份卷子在中文识别上有问题，会在试卷详情和处理队列里看到提示，不会悄悄出错。

## 装不上或不想装怎么办

- 在 **设置 → 管理员设置 → AI 服务** 里填一个支持读图的**视觉模型**，质量差的扫描页会交给它读。注意：这时这些扫描页的**图片会发给你选的 AI 服务商**（文字型 PDF 和 Word 不会发图片）。不想发图，就别填视觉模型，改装中文识别。
- 手头有文字型 PDF 或 Word，直接导入这些，最准。

## 还是不行

到卷知的 **设置 → 关于** 点 **导出诊断信息**，再点 **反馈问题**，把压缩包拖进去。诊断信息里没有学生数据和密钥。反馈里请不要写学生姓名和 API Key。
