### A3 事实核对：真实效果（能抓什么、抓不到什么）

核对是启发式的，通过只表示「和审核过的题目解释说的一致」，不表示一定对。它分三道关，对每个句子依次判断：

1. **英文短语 → 词类**（证据里写了「time for + 名词」这类关系的短语）：句子在这个短语后面（到下一个短语 / 标点 / 18 个字）说了什么词类，和证据不一致 → **与题目解释矛盾**。不看连接词怎么说（后接 / 后面要接 / 加 / 要用 / 之后要用 / 的后面应该跟），也不要求句子有「规则的口气」；认「名词 / 动词 / 动词原形 / 动名词 / doing / 形容词 / 副词」和「东西 / 动作」这种口语；前面有「不能 / 不是 / 别」会按否定算；短语后面没有词类时看前面（「动词前面用 time to」）；句子里已经写全过「time for」之后单写的「for 后面跟东西，to 后面跟动作」也会对应上。
2. **词尾**（证据里写了「tomato 的复数加 -es」）：句子里同一个词的词尾说法（加 s / es / ies / ed / ing）和证据不一致，或正好是证据里说「易误加」的那个 → **矛盾**。「典型错误：tomato 变复数不加 -es」这种描述错误的句子，方向按「错误描述」反过来看，不误报。
3. **其余的规则句**（有英文词语 + 规则口气）：句子里**每个**英文词语都要在证据里出现过，并且出现它的证据说的是同类的语法点（中文规则用语有重合），否则 → **未核实**。

**抓得到**：上面三类里换说法的绕过；证据里没有的规则（be good at、sheeps、potato、these → they）一律标「未核实」。

**抓不到 / 不保证**：
- 说法不含任何已知词类词的改写（例如「time for 后面是不是该放一个事情」）；证据里没写过关系的短语（没有「time for + 名词」这条证据，就没有「矛盾」可判，只会因为证据里没有它而标「未核实」）。
- 只有中文、没有英文词语的规则句不核对（例如「第三人称单数动词要加 s」）。
- 描述学生错误的句子（「典型错误：time for 后接动词」）对短语关系不做判断，只走第 3 道关。
- 第 3 道关看的是「证据里有没有提到这些词」，不是语义对错：句子里的词都在证据里出现过、中文用语又有重合时，即使表述有误也会通过。
- **会误标**：说得对但证据里没写的句子会被标「未核实」。真实 AI 输出回放：家长版 0 处、老师版 4 处、P2 2 处标记，都是证据里确实没有的内容（sheeps、potato、these → they、How much 的 is / are）；没有误报「矛盾」。所以「0 处标记」只表示「核对过的那些规则句没有发现问题」，不代表整份报告都对。

### A4 疑似重复：判断规则

- 对库里每一份其他卷子（状态 reviewing / done、非示例）成对比较「包含度」：A 里有多大比例的题，在 B 里也有（题干 + 选项规范化后至少 8 个字符才算一道有效题；每份至少 3 道有效题才比）。
- 达到判定线算疑似：包含度 ≥ 0.8（**不看年级学年，卷头信息读不出来时也只靠这一条**）；≥ 0.5 且年级和学年都一致；≥ 0.3 且标题完全一样。
- **对称**：两份里「被对方包含得更多」的那份（残缺的、只是其中一部分的）被标成 suspect，完整的那份计入统计；包含度一样（完全重复）标后导入的。所以先导入第 1 页、后导入整卷时，被排除的是**旧的第 1 页**（它的状态会变，因为现在知道有更完整的一份了）；先导入整卷、后导入第 1 页时，被排除的是新导入的第 1 页。老师确认过（accepted）的卷子永远不会被改状态。
- `similar_ratio` 永远是「被标的这份有多大比例的题在 `similar_to` 那份里也有」，所以界面文字「像是《X》的一部分」在两个方向都成立。
- 删掉一份卷子后，原来因它被标 suspect 的卷子重新判断（可能恢复计入）。升级到 v10 后整库按导入先后扫描一遍，也可以手动调 `papers.scanSimilar()`。
- 统计页的「有 N 份疑似重复没计入」跟随当前筛选（年级 / 学期 / 学年 / 含待审核），不再按全库算。

### 12.6 家长版再改一轮（r2 读不通 → r3）

**原因**：r2 的小标题是名词堆在一起（「西红柿绵羊」「缩写和分类」），提示词又把每条压成三个一句话的小段、总长 260 字，模型把句子写成了电报；「问 can not，答 can't」家长不知道怎么做；句末没有标点。

- 提示词（`p3_parent`）：每条只讲一件事（易错原因里有两件事只挑主要的）；不要小标题；每条 3 句完整的话：错在哪（英文词后带括号中文）→ 在家做（问一个一听就懂的问题）→ 标准答案（「说出 X（中文）就对了」）；明确禁止「问……，答……」；总长 210–280 字；带一个句式示范（只学句式）。

- 回归单测：`tests/unit/parent-fix.test.mjs` 把 r2 里的 3 个坏条目（含「西红柿绵羊：」「缩写和分类：」「问 can not，答 can't」）写成反例。
