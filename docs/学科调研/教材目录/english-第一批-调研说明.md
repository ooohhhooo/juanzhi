# 小学英语教材目录 · 第一批扩充调研说明（12 个版本）

核对日期：2026-11-12。数据文件都在 `src/main/seed/textbook-catalog/`，并已在 `index.ts` 中登记。

原则（用户决定）：**版本都合到一起，不追新旧版**。每册只收一份当前最容易核到的目录：2024 年起新版已出的册用新版，其余用现行版。editionYear 照实填，查不到准确年份的写最可能的年份（下表标「估」）。单元标题照课本原文；`lessons` 里的句型除注明「原句」的以外都是按单元主题概括的（写作「句型（概括）」）；`kps` 是按单元话题和句型判断的，只用 `taxonomy.ts` 中已有的代码。

## 三、收录方式

- 复习单元（Revision / Recycle / Review / Review Module / Assessment / Fun time / General Revision）都单独收一条。冀教版的单元末栏目（Again, please! / Project time / Unit n Review）在单元内部，写进该单元的「课文」行，不单独收。
- 外研版（一起）一个 Module 收一条，标题写成 `Module n Unit 1 … / Unit 2 …`。湘鲁版新版虽然也分 Module，但每个 Unit 单独成课、全册连续编号，所以按 Unit 收，模块名写进 lessons。
- 冀教版、北师大三起新版、闽教新版在「课文」行列了 Lesson 标题原文。闽教新版目录页有 Key patterns 一栏，句型用的是原句；其他版本的句型都是概括的。
- 附录（Words in each unit、Vocabulary、Plays 等）和拓展阅读（湘少版 Let's Know More 等）不收。
- 电子课本网的明显错字已经改正，例如 Linglingi、Do't、scince、Mockey's。原文缺的「Unit」前缀也补上了。

## 四、拿不准的地方

1. **大多数 editionYear 是估计的**，特别是现行版各册和一年级起点各套，都没核到版权页。只有闽教版 5下、6下核到了版权页（2014 年 12 月第 1 版）。
2. **各套的 5下、6下用的是现行版**，因为截至核对日新版目录都还没公开。北师大一起的 2下也可能已经改版，但两个来源都还是老目录。
3. **湘鲁版只有电子课本网一个来源**，有条件时建议用智慧教育平台或纸书核一遍。六下「Unit 8 We will be a junior middle school.」照网页原样保留，疑似少了 students。湘少版三下、四上的目录没有列 Assessment，所以没收。
4. **两个来源不一致的地方**：
   - **外研一起 5上 Module 3**：教习网显示名是 They're all my favourite festivals! / They made moon cakes for the animals.，电子课本网和教习网目录树写的是 Today is Halloween. / Easter is in spring in the UK.，JSON 用的是前者。另外 1上 M5U2 用 This（不是 That），1下 M4U2 用 legs（不是 eyes），3上 M1U1 用 in England，M10U1 用 go to Hong Kong，6下 M5U2 用 in the water。
   - **北师大一起**：4上 U2/U4、5上全册、5下 U7/U10 的标题用的是英语朗读宝的新写法，电子课本网的老写法记在 unit.note（「部分资料单元名写作 …」），方便对上老试卷。6上 U3 用 Redrock Bay Health Club（朗读宝写 Sports Club）。
   - **冀教三起四下**：Lesson 标题有 6 处两个来源不同，用的是电子课本网的写法，有一份 21世纪教育网课件能对上。四上 U2 L3、五上 U4（Countries in the world）、六上 U3（Volunteering）也按电子课本网。
   - **闽教 5下 Unit 3**：智慧教育平台上的现行课本（2025 年 12 月印）是 Zhong Nanshan，电子课本网写的是 Easter eggs，用了前者。
   - **大小写**：人教精通 6上 U2、U3 按句首大写；重大版 5下、6下用 Good helpers。
5. **句型和 kps 可信度**：除了闽教新版，句型都是概括的，没有逐课对照课本。高年级新版（如重大版 Fun Science、Colourful Arts 这类主题比较宽的单元）的语法代码可信度最低。taxonomy 里没有颜色、植物、环保、科学这类话题代码，这些单元只标了语法和交际代码，或借用了相近的话题代码（比如 VO.TOPIC.ANIMAL 用于「动物与自然」，VO.TOPIC.CLOTHES 用于颜色）。

## 五、校验

- 每个文件都过了 `validateEdition`（`tests/unit/textbook-catalog.test.mjs`）：年级、学期、单元序号不重复，知识点代码都在 `KP_SEEDS_V1` 里，textbookValue 在英语教材列表里。单测里也加了这 12 个 id 已登记的断言。
- 另外检查了每个单元有 1–8 个 kps，note 里没有「旧版」「待替换」之类的说法。
