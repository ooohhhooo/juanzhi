# 小学语文统编版（六三制）教材目录：调研说明

> **2026-11-12 补充**：用户决定各版本「合到一起、不追新旧版」。四下、五下、六下就用现在这份目录，以后不再计划替换；JSON 里这几册的 `note` 已改成只写目录对应的年份，不再写「暂收」「待替换」。下文里「先收旧版、新版出来后要更新」之类的说法以这条为准。

> 调研日期：2026-11-11。数据文件：同目录 `chinese-tongbian.json`（12 册，95 个单元条目，其中一上的「我上学了」入学教育记为第 0 单元）。
> 只收目录信息：单元、课文标题、栏目名，以及单元语文要素的简短概括。不收课文正文。

## 一、新旧版怎么判断

统编语文按三年计划换成新修订版：2024 年秋一年级先换，2025 年秋二、三年级换，2026 年秋四至六年级换（澎湃转央视报道、北京日报 2026-09-01）。具体到 2026–2027 学年的 12 册：

| 册 | editionYear | 判断 |
|---|---|---|
| 一上 | 2024 | 新修订版，2024 秋启用 |
| 一下 | 2025 | 新修订版，2025 春启用 |
| 二上、三上 | 2025 | 新修订版，2025 秋启用 |
| 二下、三下 | 2026 | 新修订版，2026 春启用 |
| 四上、五上、六上 | 2026 | 新修订版，2026 秋启用（本学期正在用） |
| 四下、五下、六下 | 2019 | **暂收原版**。按计划 2027 春应换新修订版，但截至 2026-11-11 新版下册目录还没公开（电子课本网的人教版语文栏目里，这三册仍只有原版）。JSON 里这三册的 `note` 写明了这一点，新版出来后要更新。 |

所以：新修订版 9 册，原版 3 册。

主来源是电子课本网（dzkbw.com）人教版语文各册的目录页。它按实体课本逐页扫描，目录带页码，册名标了版次（如「三年级语文上册（2025秋版）」）。每册另找了至少一个独立来源核对：

## 三、知识点标注口径

- 代码全部取自 `src/main/seed/taxonomy-chinese.ts`（110 个），已用 node 校验：每个单元 1–6 个代码，没有一个不在树里。
- 和《知识点树草案》保持一致：
  - 优先标到最具体的一层，比如 `CN.ACCU.POEM.RECITE`，不标 `CN.ACCU`。
  - 阅读单元按单元语文要素，选 `CN.READ.SKILL.*` 或 `CN.READ.GENRE.*`。
  - 小古文标 `CN.ACCU.CLASSIC.*`。
  - 「快乐读书吧」标 `CN.READ.BOOK`，口语交际标 `CN.ORAL.*`，习作按类型标 `CN.WRITE.*`。
- 知识点树里没有的东西不硬编代码，都在 note 里写明：
  - 三上的「预测」策略单元，用 `READ.GENRE.STORY` 和 `READ.SKILL.RESPONSE` 近似。
  - 四上的「提问」策略单元，用 `READ.SKILL.RESPONSE` 近似。
  - 五上的「提高阅读速度」单元，用 `LOCATE`、`SUMMARY` 近似。
- 一、二年级识字单元标到 `CN.CHAR.*` 和 `CN.WORD.*`，拼音单元标到 `CN.PY.*`。

## 四、拿不准的地方

1. **一、二年级新版的口语交际**：电子课本目录页里，一上至二下都没单列「口语交际」，原版是单列的。可能编进了语文园地，也可能只是目录页没写，没查到确证。JSON 里这四册都没列口语交际。
2. **三上两组「古诗三首」的篇目**：目录页只写了「古诗三首」，没列诗名。原版第二单元是《山行》《赠刘景文》《夜书所见》，原版第六单元是《望天门山》《饮湖上初晴后雨》《望洞庭》。新版的古诗三首在第二、第七单元，推测篇目沿用原版，但没有核实，所以 JSON 里只写「古诗三首」。
3. **三下第五单元**：目录页没列交流平台、初试身手和习作例文，新版是否保留不确定。
4. **四上《女娲补天》**：搜狐梳理文章说新版已经移出，但电子课本目录仍然有（第 14 课）。按课本收，并在 note 里注明。
5. **新版语文要素**：新修订版的单元导语没拿到原文。下面这些单元的 note 都标了「新版单元导语未逐字核对」或「按内容推断」：
   - 和原版同类的单元：要素按原版概括。
   - 新增或重组的单元：要素按课文内容推断，涉及二上三单元、二下八单元、三下六单元、四上六单元、六上七单元。
   - 以下几处有地方教研资料印证：一下八单元、二上八单元、三上一和三单元、三下一单元。
6. **原版下册的印次差异**：电子课本网收的是较新印次，和 2020 年预发布目录有出入。JSON 按较新印次收。
   - 四下：文言文二则在第六单元，预发布目录放在第七单元。
   - 五下：第四单元《青山处处埋忠骨》排在《军神》前。
   - 六下：第 13 课由《金色的鱼钩》换成《董存瑞舍身炸暗堡》。
7. **单元标题括号里的主题词**（如「学校生活」「金秋时节」）是按单元人文主题概括的，不是课本原文，界面展示时可以只用「第 X 单元」。
8. 略读课文没有标 `*`，课次编号也没收（一、二年级识字和阅读课分别编号，容易混）。
9. JSON 每册多了一个 `note` 字段，写明是新修订版还是原版。如果消费端不认这个字段，直接忽略就行。
