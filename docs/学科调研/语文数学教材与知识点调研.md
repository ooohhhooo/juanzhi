# 小学语文、数学：教材版本、知识点树与识别难点调研

> 调研日期：2026-11-10。资料来自公开报道和地方教育部门文件，下文逐条标了来源和可信度。
> 配套数据：同目录《知识点树草案.md》（两棵知识点树、两张题型表、白话释义）。

## 一、先说结论

1. **语文只有一套教材：统编版**（也叫部编版，人民教育出版社出版），全国通用，五四学制地区用它的五四学制版。2017 年启用后第一次大修订，**2024 年秋一年级先换，2025 年秋二、三年级跟进，2026 年秋四至六年级换完**。到现在（2026 年 11 月），全国小学各年级都在用新修订版。
2. **数学有多个版本，人教版用得最广**，其次是北师大版、苏教版（江苏全省）、青岛版（山东）、冀教版（河北部分地区）、西师版（西南部分地区）、北京版（北京部分区）、沪教版（上海）。各版本都按《义务教育数学课程标准（2022 年版）》修订，**换版节奏和语文一样：2024 一年级、2025 二三年级、2026 四至六年级**。
3. **新教材有实打实的内容变化，影响知识点标注**。最大的一处：人教版新五年级上册删掉了解方程、列方程解应用题（课标把方程移到初中）。其他还有「位置（数对）」从五上移到六上、「公顷和平方千米」从四上移到五上、「植树问题」降为选学、新增尺规作图等。用户手里的试卷新旧教材都有，知识点树必须**两边都能标**，所以保留了「方程」这类节点，并标注【旧教材】。
4. **知识点树按知识点组织，不按单元组织**。各版本单元顺序不同，但都按同一份课标编，知识点集合基本一致。数学树 147 个节点，语文树 110 个节点，都是三级。
5. **识别上最要紧的三件事**：
   - **数学的竖式、脱式、分数要按图片理解，不能只靠逐行 OCR 文字**。系统 OCR 会把竖式拆成散落的数字、把分数读成两行。凡是检测到竖式、分数、几何图形的页面，都应该走视觉模型。
   - **语文的「看拼音写词语」和「给加点字注音」依赖版面**。拼音写在格子上方，加点字的点在字下方，OCR 都会丢掉。声调符号（ā á ǎ à、ü）也经常被识别错。
   - **只用来标知识点时，影响比看上去小**。卷知主要统计「这道题考什么」，不判对错。题干能大致认出来、题型和知识点能标准，就够用了。真正要精确识别的，只有学生答案和手写批改，这部分先不承诺。

## 四、知识点树怎么设计的

### 4.1 依据

- **数学**：《义务教育数学课程标准（2022 年版）》小学阶段有四个领域：数与代数、图形与几何、统计与概率、综合与实践。其中，数与代数又分「数与运算」「数量关系」两个主题，图形与几何分「图形的认识与测量」「图形的位置与运动」两个主题。课标分三个学段：1–2 年级、3–4 年级、5–6 年级。
- **语文**：《义务教育语文课程标准（2022 年版）》的学段目标有四块：识字与写字、阅读与鉴赏、表达与交流、梳理与探究。课程内容用六个「学习任务群」组织：语言文字积累与梳理；实用性阅读与交流；文学阅读与创意表达；思辨性阅读与表达；整本书阅读；跨学科学习。
- 二、三级节点参考了人教版、北师大版、苏教版数学和统编版语文的单元内容，再按试卷上实际怎么出题来拆分。

### 4.2 为什么不直接照搬课标的结构

课标的结构是给教学用的，不是给试卷标注用的。

- **数学**：课标把「解决问题」散在各个主题里，但试卷上「解决问题」往往占三成分数，老师最关心学生卡在哪类应用题上。所以单独设了一级 `MA.PROB`，下面按价格、行程、工程、分数百分数等模型拆分。同理，「数学广角」类的思维题（鸡兔同笼、植树、搭配）也单独设了一级 `MA.THINK`。
- **语文**：学习任务群太抽象，一道「把字句改被字句」的题很难归到某个任务群里。所以一级按试卷板块分：拼音、识字写字、词语、句子、古诗文积累、阅读、口语交际、习作。这也是家长和老师最熟悉的分法。

### 4.3 一级节点一览

| 数学 | 语文 |
|---|---|
| MA.NUM 数的认识 | CN.PY 汉语拼音 |
| MA.CALC 数的运算 | CN.CHAR 识字与写字 |
| MA.ALG 数量关系与代数初步 | CN.WORD 词语 |
| MA.MEAS 常见的量 | CN.SENT 句子（含标点） |
| MA.GEO 图形与几何 | CN.ACCU 古诗文与积累 |
| MA.STAT 统计与概率 | CN.READ 阅读理解 |
| MA.PROB 解决问题 | CN.ORAL 口语交际 |
| MA.THINK 数学思考与综合实践 | CN.WRITE 写话与习作 |

### 4.4 几个具体的取舍

1. **新旧教材都能标**。2022 年版课标移走或降级的内容（方程、植树问题）照样保留，节点名里加【旧教材】。这样分析往年卷时不会无处可标，做「新旧教材对比」时也能看出这些题在减少。
2. **年级只是提示**。「常见引入年级」取多数版本的位置，版本之间差一个学期很常见（比如人民币、数对）。不要用它判断「超纲」。
3. **计算题和应用题分开标**。一道应用题如果主要考计算（比如分数除法），主知识点标 `MA.CALC.FRAC.DIV`，次知识点标 `MA.PROB.*`。这和英语树「能判断具体语言点时优先标语言点」的规则一致，需要写进解析提示词。
4. **阅读题先标具体能力**。语文阅读题如果考的是修辞、关联词，就标到 `CN.SENT.*`。只有考概括、理解、情感这类阅读能力时，才标 `CN.READ.*`。
5. **代码前缀和层级**。按现有 `buildKpRows` 的规则，层级由「父节点是否存在」推导。`MA`、`CN` 不建根节点，所以 `MA.NUM` 自动是一级，`MA.NUM.FRAC.COMPARE` 是三级，不会超过三层。代码都符合现有的命名正则。
6. **题型表沿用英语的思路**。数学 21 个题型，语文 27 个，最后一个都是「其他」。英语题型表有一列 `listening/written`，语文、数学都没有听力题，这一列可以统一填 `written`。

## 五、OCR 和 AI 识别的难点与对策

背景：卷知现在的识别流程是三层。先用 PDF 自带的文字层；没有文字层就用系统 OCR（Mac 用 Vision，Windows 用 Windows OCR）；置信度低时再交给视觉模型。系统 OCR 只按行返回文字，不懂版面。

### 5.1 数学

| 难点 | 具体表现 | 建议 |
|---|---|---|
| 竖式 | 竖式是二维排版，OCR 按行读出来是一串互不相关的数字，进位点、退位点、横线都会丢 | 竖式题不需要还原计算过程，标题型（`MA_VERTICAL`）和知识点就够了。提示词里写明：「连续多行、按位对齐的数字是竖式」。页面里有竖式时，建议直接走视觉模型 |
| 分数 | 上下结构的分数，OCR 常读成上下两行，或者读成「3 4」「3/4」「34」；带分数更乱 | 分数密集的页面（五、六年级）走视觉模型。提示词要求统一输出 `a/b`、带分数输出 `1又3/4` |
| 脱式计算 | 等号竖着对齐，每行开头只有一个「=」 | 和竖式一样，按题组整体理解，不逐行解析 |
| 几何图形 | 题目信息在图里（边长、角度、阴影），OCR 只能拿到零散标注，比如「5cm」「60°」 | 知识点靠题干文字（「求阴影部分面积」）基本能判断。需要图中信息时走视觉模型。题目框选区域要把图包进去 |
| 单位和符号 | cm²、m³ 的上标读成 cm2；「×」读成 x 或 X；「÷」丢失；「○」「□」「（ ）」空位丢失；°、π、≈ 识别不稳定 | 在交给 AI 之前加一步规则校正（比如数字之间的 x 改成 ×，cm2 改成 cm²）。提示词里说明：「○ 里填 >、<、=」「（ ）是填空位」 |
| 统计图、方格纸、钟面、数轴 | 内容全在图里 | 走视觉模型。只用来标知识点时，看题干一般就够了 |
| 口算题一页几十道 | 题号不清，AI 容易把每道小算式都拆成一题 | 规定「口算、竖式、脱式按大题整体算一题」，或者按小题拆但共享知识点。**需要拍板**（见第六节） |

### 5.2 语文

| 难点 | 具体表现 | 建议 |
|---|---|---|
| 拼音和声调 | 声调符号 ā á ǎ à 常被识别成 a 或其他字母，ü 变成 u 或 v；拼音和汉字混排时，OCR 会把拼音行和汉字行串在一起 | 「看拼音写词语」只用来标知识点时，拼音认错影响不大（知道是这个题型就行）。要还原题目内容时，走视觉模型 |
| 田字格、米字格 | 格线被识别成「十」「口」「田」或乱码；空格子会被认成字 | 文字层清洗时去掉大面积重复的「口」「田」「十」。提示词说明：「格子是作答区，不是题目内容」 |
| 加点字 | 字下面的点 OCR 完全看不到，「给加点字注音」就不知道是哪个字 | 不影响题型和知识点判断（`CN.CHAR.SOUND.READ`）。要知道是哪个字只能靠视觉模型。下划线、波浪线、括号同理 |
| 作文格 | 习作页面整页都是方格，OCR 会产生大量噪声，甚至超时 | 识别到整页格子时直接只取题目要求部分。习作题干通常在格子上方，提示词说明：「方格区是作答区」 |
| 竖排古诗、繁体字 | 少数试卷用竖排、书法字体、插图 | 少见，走视觉模型兜底 |
| 题干长、材料多 | 阅读材料一页多，题目在后面，AI 拆题时容易把材料和题目混在一起 | 沿用英语阅读的做法：材料挂在第一个小题上，或者作为大题的公共材料 |

### 5.3 两科共同的问题

- **手写答案和批改痕迹**：学生作答、红笔批改会严重干扰 OCR。如果用户导入的是做过的卷子，建议提示「尽量导入空白卷或电子版」。
- **扫描质量**：低分辨率扫描时，拼音声调、小数点、分数线最先丢失。可以在导入时检测分辨率，低于约 150 DPI 时给出提醒。
- **成本**：如果数学、语文大量页面走视觉模型，调用费用和耗时都会比英语高。建议先拿 20–30 份真实试卷做抽样测试，统计有多少页需要视觉模型，再决定默认策略。

## 六、需要产品负责人拍板的事

1. **口算、竖式、脱式怎么拆题**：一个大题算一题，还是每个小算式算一题？前者统计更干净，后者能看出具体哪类算式错得多。（卷知不判对错，所以倾向前者。）
2. **旧教材内容怎么处理**：方程等【旧教材】节点是默认显示，还是做成「旧教材专用」、新卷不推荐？
3. **教材版本字段**：数学要不要列出全部 8 个版本供选择？西师版、北京版、沪教版用户少，可以合并成「其他」。
4. **数学、语文默认走视觉模型的条件**：按年级（五、六年级数学分数多）、按题型，还是按 OCR 置信度？这会直接影响用户的调用费用。
5. **作文和阅读能不能只标题型、不细标知识点**：习作的「写人、记事」可以从题目判断，但「写作手法」这类要看学生作文。建议只按题目要求标注。
6. **版本分布表是否放进产品**：地区和版本的对应关系可信度大多是「中」「低」，建议只放在文档里，不放进软件。
