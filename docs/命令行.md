# 卷知命令行（1.2.0 起）

卷知除了窗口，还可以在终端里一行命令完成：导入试卷、看统计、生成报告、导出文件。适合两类人：

- **Agent**（Codex、Claude Code、WorkBuddy 这类能执行命令的助手）：让它们直接调用卷知；说明书在 `skills/juanzhi/SKILL.md`。
- **自己**：把重复的事写成脚本。

## 怎么调用

同一个程序，第一个参数写 `cli`：

| 系统 | 完整写法 |
|---|---|
| Mac | `"/Applications/卷知.app/Contents/MacOS/卷知" cli status` |
| Windows（安装版） | `"C:\Users\你的用户名\AppData\Local\Programs\EnglishExamWorkbench\EnglishExamWorkbench.exe" cli status` |

每次都敲这么长不方便：在卷知窗口里打开 **设置 → 管理员设置 → 命令行工具 → 安装命令行工具**，会装一个短命令 `juanzhi`：

- **Mac**：写到 `~/.local/bin/juanzhi`。如果提示这个目录不在 PATH 里，在终端运行 `echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc`，重新打开终端。
- **Windows**：写到 `%LOCALAPPDATA%\Juanzhi\bin\juanzhi.cmd`，并加进你的用户 PATH（不需要管理员权限）。重新打开 PowerShell / 命令提示符后生效。
- **免安装版（portable）的限制**：短命令指向免安装文件本身，移动或删除它后就失效；每次运行都要先解压，慢几秒；它的外层启动器不一定传递退出码（看返回 JSON 里的 `ok` / `exit`）。长期给 Agent 用，建议装安装版。
- 想改装在别处、或卷知被移动 / 重装后，重新点一次「安装命令行工具」即可。

装好之后：

```
juanzhi status
juanzhi import "C:\卷子\g4-2025.pdf" --wait
juanzhi report generate --reader boss --grade 4
```

## 使用前必读

- **先退出卷知。** 窗口和命令行不能同时使用同一份数据：卷知开着时，命令行会报「请先退出卷知再用命令行」（退出码 3）。**Mac 上只关窗口不等于退出**（关了窗口卷知还在运行，要按 Cmd+Q 或在菜单里选「退出卷知」）；Windows 上关闭窗口就是退出。命令行在运行时打开窗口，窗口会提示等它结束（如果命令行卡住了，提示框里有「结束命令行任务并打开」）。两个命令行同时跑，第二个会报退出码 4。这把「锁」是系统级的：命令行被强杀、断电之后会自动释放，不会留下需要手动清理的东西。
- **先在窗口里配好 AI。** 命令行不能设置、也读不到 API Key。没配时 `import` 和 `report generate` 报「请到设置 → AI 服务里填写」（退出码 5）。
- 命令行**不能删除**试卷或报告，也不能改数据目录（数据目录只认环境变量 `EWB_USER_DATA_DIR`，那是给测试用的）。生成报告时，超过历史上限（100 条）最旧的报告会被自动清理，和窗口里的行为一样。
- 结果文件（`--result-file` / `--out`）不能写进卷知的数据目录，已经存在的文件如果不是卷知以前写的结果文件也不会被覆盖；`report export` 目标文件已存在时要加 `--overwrite` 才覆盖。
- 更新卷知后第一次读 AI 配置时，Mac 可能弹出钥匙串授权框：先在窗口里打开一次卷知，选「始终允许」，命令行才不会卡在这个框上（命令行没有窗口，看不到它）。
- 命令行模式不会出现任何窗口或对话框，Mac 上运行期间没有可见的 Dock 图标。

## 输出

- **stdout 只有一段 JSON**：成功 `{"ok":true,"data":{…}}`；失败 `{"ok":false,"code":"…","message":"中文白话","exit":N}`。**输出是纯 ASCII**：中文等非 ASCII 字符写成 `\uXXXX`，仍然是合法 JSON，任何 JSON 解析器读出来都是原来的中文；这样 Windows 的 PowerShell / cmd 不管控制台用什么编码（中文系统是 GBK）都不会乱码。用文本方式直接读 stdout 的人会看到转义，请用 JSON 解析器（PowerShell 的 `ConvertFrom-Json`、Python 的 `json.loads`、`jq`）。
- 进度和日志写在 **stderr**（每行以 `[juanzhi]` 开头），读结果时可以忽略。
- `--out <文件>`：把同样的 JSON 同时写进文件（`report export` 里的 `--out` 是导出文档的路径，JSON 副本请用 `--result-file <文件>`；`--result-file` 在所有命令里都能用）。
- `--timeout <秒>`：`import` 最多等多久（默认 3600）；`--quiet`：不写 stderr 进度。

### 退出码

| 码 | `code` | 含义 |
|---|---|---|
| 0 | — | 成功 |
| 1 | `internal` | 没预料到的内部错误（message 里有原因） |
| 2 | `usage` | 命令或参数不对（缺参数、未知命令、筛选值非法、id 格式不对） |
| 3 | `app_running` | 卷知窗口正在运行：请先关闭卷知窗口再用命令行 |
| 4 | `cli_busy` | 另一个命令行任务正在使用数据，等它结束后再试 |
| 5 | `ai_not_configured` | 没配 AI：到窗口的「设置 → AI 服务」里填写 |
| 6 | `not_found` | 试卷 / 报告 id 不存在 |
| 7 | `invalid_state` | 当前状态不允许（试卷还没解析完、范围内没有可统计的卷子……） |
| 8 | `confirmation_required` | `papers confirm` 没带 `--i-reviewed` |
| 9 | `import_failed` | 有文件没能导入 / 提取 / 解析（`data.papers` 里有每份的结果） |
| 10 | `timeout` | `import` 等待超时（命令行退出后没处理完的任务不会继续，卷子会退回「已提取」或标失败，可以到窗口的处理队列里重试） |
| 11 | `export_blocked` | 导出被拦（家长版内容太少、有没能删掉的矛盾句、超过 300 字） |
| 12 | `busy` | 现在有别的后台任务占着（稍后再试） |
| 13 | `data_unavailable` | 数据目录不可用或数据库打不开 |
| 14 | `ai_failed` | AI 服务调用失败（网络、密钥无效、额度……） |

### Windows：怎么拿到输出和退出码

Windows 上卷知是「窗口程序」：直接在 cmd 或 PowerShell 里运行 `…\EnglishExamWorkbench.exe cli status`，shell 不会等它结束，也拿不到它的输出和退出码。有两种办法：

1. **用 `juanzhi` 短命令（推荐）。** 它内部会等程序结束，把结果打到 stdout，并返回退出码。在 cmd 和 PowerShell 里都是同步的：

   ```powershell
   juanzhi status
   if ($LASTEXITCODE -ne 0) { "失败，退出码 $LASTEXITCODE" }
   ```
   ```bat
   juanzhi status
   if errorlevel 1 echo 失败
   ```

2. **直接调用 exe**，让它把结果写进文件，自己等进程结束再读：

   ```powershell
   $exe = "$env:LOCALAPPDATA\Programs\EnglishExamWorkbench\EnglishExamWorkbench.exe"
   $p = Start-Process -FilePath $exe -ArgumentList 'cli','status','--result-file','C:\temp\r.json' -Wait -PassThru
   $p.ExitCode
   Get-Content C:\temp\r.json -Raw | ConvertFrom-Json
   ```
   ```bat
   start "" /wait "%LOCALAPPDATA%\Programs\EnglishExamWorkbench\EnglishExamWorkbench.exe" cli status --result-file C:\temp\r.json
   echo 退出码 %ERRORLEVEL%
   type C:\temp\r.json
   ```

   含 `&`、`|` 的参数（如 `--textbook "A&B"`）经 `juanzhi.cmd` 转给 cmd 时可能被当成命令分隔符，这种情况请直接调用 exe，或把参数写成 `--textbook=A^&B`。

   **退出码以 `ok` / `exit` 为准**：短命令返回的退出码取自程序写的结果文件；直接调用 exe 时，如果程序在打印完结果之后异常退出（进程退出码不在 0–255 之内），JSON 里的 `ok` 和 `exit` 才是准确的。

Mac 上不需要这些：直接调用就是普通命令行程序，stdout 和退出码都正常。

## 命令

### `status`
版本、数据目录、卷子数（按状态）、AI 是否已配置（只说有没有，**绝不输出密钥**）、OCR 是否可用。

### `import <文件…> [--wait]`
导入试卷（pdf、jpg、png、heic、docx），自动提取文字并交给 AI 解析。**提取和解析在命令行进程里做，所以命令会一直等到每份卷子进入「待审核」或失败**（`--wait` 写不写效果一样，写上更清楚）。结果里每份有 `paperId`、`status`（`reviewing` / `failed` / `duplicate` / `rejected`）、题数。内容相同的文件不会重复导入（`status: duplicate`）。

导入后的卷子是 **「待审核」**：AI 解析的题型、分值、知识点可能有错。请在卷知窗口里审核；统计默认只计入已确认的卷子，加 `--include-reviewing` 可以把待审核的也算进去。

### `papers list [--grade --semester --year --exam-type --textbook --region --status]` / `papers show <id>`
列出试卷 / 看一份试卷的题目（题型、分值、知识点名称、难度、是否已确认）。

### `papers confirm <id> --i-reviewed`
**跳过人工审核，把整份试卷的所有题直接标为「已确认」。** 风险：AI 解析会有错，这些错会直接进入统计和报告。必须加 `--i-reviewed` 才执行，等于你声明「我已经审核过了」；不加会报退出码 8，提示应该在窗口里审核。

### `stats overview | hot | compare`
和界面一致的统计，支持筛选：`--grade 1-6`、`--semester 上|下`、`--year <学年起始年>`、`--exam-type 单元测试|期中|期末|月考|其他`、`--textbook`、`--region`、`--include-reviewing`、`--include-duplicates`。`hot` 可加 `--level 1|2|3`；`compare` 要 `--target <学年> [--base before|<学年>]`。样本太少时返回里有提示，不会下「难点」结论。

### `report generate --reader boss|teacher|parent|full [筛选]`
生成报告（要先配好 AI）。返回 `id`、`markdown`、`unverified`（事实核对没通过的句子，请逐条转告使用者）、`warnings`、`draft`。事实核对、家长版把关、样本不足提示、内部代码过滤和窗口里一样生效。

### `report list` / `report show <id>`
报告列表 / 一份报告的完整内容。

### `report export <id> --format md|docx|pdf --out <路径>`
导出文件。**家长版如果没有在窗口里点过「我已核对」，导出的文件开头会有醒目的「AI 草稿 · 未经老师核对，请勿直接发给家长」，返回的 JSON 里 `parentDraft: true`、`draft: true`。`draft` 对所有版本都表示「没有老师在窗口里点过『我已核对』」（都是 AI 草稿，`reviewed` 为 false）；`parentDraft` 只表示家长版的文件开头带了「请勿直接发给家长」标记。** 命令行没有替老师点「我已核对」的命令：家长版必须由老师在窗口里读一遍、改掉不对的地方、点「我已核对」。内容太少 / 有没能删掉的矛盾句的家长版仍然拒绝导出（退出码 11）。

## 典型流程

```
juanzhi status                                   # 看 AI 是不是已配置
juanzhi import 卷子1.pdf 卷子2.pdf --wait        # 导入、等解析（几分钟）
# → 提醒使用者：到卷知窗口里审核这几份卷子（或确认已审核）
juanzhi papers confirm <id> --i-reviewed         # 只有使用者说「我已经审核过了」才用
juanzhi stats overview --grade 4
juanzhi report generate --reader teacher --grade 4
juanzhi report export <id> --format docx --out ./老师版.docx
```
