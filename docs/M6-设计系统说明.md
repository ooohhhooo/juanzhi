### 对比度（已计算，均 ≥ 4.5:1）

浅色：次要文字在画布 6.4、在灰底 5.4；主色在画布 5.6、在灰底 4.8、在主色浅底 4.9；白字在主色 5.6；白字在玫红 4.56；易错文字版在画布 6.2、在红色浅底 5.6；墨色在六色浅底 14 以上。
深色：次要文字在画布 7.1；主色在画布 6.5、在主色浅底 5.3；易错文字在红色浅底 5.2；六色浅底上的次要文字 4.7 以上。选中和悬停的拇指标签把数量改成墨色（次要文字在加深的底上只有 3 到 3.9）。

### 字体、字号、间距、形状、动效

- **字体**：西文、数字、音标用 Source Sans 3 Variable（`@fontsource-variable/source-sans-3`，正体 + 斜体，woff2 随应用打包，完全离线）；中文用系统黑体栈（PingFang SC、Microsoft YaHei、Noto Sans CJK SC、Source Han Sans SC）。第二版**没有换成圆体**：换字体的前提是 OFL、离线、带斜体、能显示音标，而例句里的 /iː/、/e/ 要靠 Source Sans 3 的 latin-ext 子集显示；圆润感由胶囊和大圆角承担。
- **打包检查**：构建产物 `out/renderer/assets/*.woff2`，CSS 里是相对路径 `url(./source-sans-3-…woff2)`，`file://` 加载没问题；E2E 里 `document.fonts.check` 正体和斜体都通过。
- **字号阶梯**：12 / 13 / 14（正文）/ 16 / 18 / 22 / 30 / 44。44 只给大字结论里的数字。数字用 `tabular-nums`（`.ewb-num`，表格、统计、标签默认带）。
- **间距**：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64。
- **形状**：卡片和面板 18、控件 12、小块 8、画布 24；按钮、标签、状态标签、范围条里的小按钮都是胶囊（999）。卡片 1px 细线，不加阴影；只有浮层有阴影。
- **动效**：状态过渡 150 / 200ms；标志动效是拇指索引翻页，横向滑入 240ms，指数缓出 `cubic-bezier(0.16, 1, 0.3, 1)`；`prefers-reduced-motion` 下全部关闭（CSS 兜底，E2E 验证翻页动画在减少动态效果时为 0）。

### AntD 主题

`antdTheme(mode)` 返回完整 `ThemeConfig`：`algorithm`（浅色默认算法、深色 darkAlgorithm）+ 全局 token + 组件 token（Layout、Button、Input、InputNumber、Select、TreeSelect、Tree、Table、Tabs、Modal、Drawer、Tag、Tooltip、Popover、Message、Notification、Switch、Menu、Dropdown、Segmented、Alert、Card、Collapse、Statistic、Steps、Progress、Checkbox、Radio、Form、Divider、Badge、Pagination、Empty、Skeleton、Spin、List、Descriptions、Upload、Slider）。token 管不到的地方（焦点环、表格边线、弹层边框与阴影、实心危险按钮文字）在 `design.css` 里用 `html.ewb-design …` 选择器覆盖。已用截图验证：按钮（主 / 次 / 危险 / 安静 / 加载 / 禁用）、输入框、Select 和下拉、Segmented、Switch、Checkbox、Tabs、Table、Modal、Drawer、Dropdown、Message、Tooltip、Popover。

### ECharts 主题

项目目前**没有安装 echarts**（矩形树图是纯 DOM）。`echartsTheme(mode)` 只返回主题对象，`registerEChartsThemes(echarts)` 接收 `import * as echarts from 'echarts'` 后注册为 `ewb-light` / `ewb-dark`，`useTheme().echartsTheme` 给出当前名字。系列色按六大类固定顺序，坐标轴、网格线、提示框、热力（单一主色深浅）都已设置。分布页的横条图建议用 `BarList`（纯 DOM，条形按大类着色，旁边有数字和文字），不必引入 echarts。

### 主题切换

跟随系统 + 手动（浅色 / 深色 / 跟随系统），偏好存 `localStorage['ewb-theme-pref']`（读写都 try/catch）。`installTheme()` 在渲染前注入 CSS 变量并写 `<html data-theme>`；`ThemeProvider` 监听系统变化。`useTheme()` 返回 `{ pref, mode, setPref, echartsTheme }`。侧栏底部是 `ThemeCycle`（点一下按 浅色 → 深色 → 跟随系统 循环），组件样板里有三选一的 `ThemeSwitch`。深色模式下原卷和页面图用 `PaperSheet` 包住，保持白纸。

## 四、组件清单与用法

```tsx
import { Entry, UsageNote, ThumbIndex, PageTurn, Headline, GuideWords, ScopeBar, Glossary, StatusLabel, ThinkingBar,
  Btn, Page, Panel, SectionTitle, EntryColumns, IndexTable, EmptyState, PaperSheet, Cloth, BarList, HeatCell, ReaderTag, Contents } from '../design'
```

### `Entry` 词条（最核心）

三种尺寸：`compact` 紧凑（列表，一行一条，无卡片）、`standard` 标准（总览，白底 1px 细线卡片，圆角 18）、`full` 完整（详情抽屉，无卡片，词头 30px）。

```tsx
<Entry
  size="standard"
  term="名词复数" examples={['books', 'boxes', 'children']} category="grammar"
  tags={[
    { label: '考过 2/2 份', hint: '这 2 份四年级期末卷里，2 份都考到了名词复数。' },
    { label: '易错', kind: 'mistake', hint: 'AI 估计其中 6 道题学生容易做错（是估计，不是真实成绩）。' }
  ]}
  plain="一个变成两个以上时，名词要变形：多数加 s，…"          // 数组 = 多个义项，标 ①②③
  examplesSentences={[{ en: 'Those are tomato**es**.', zh: '那些是西红柿。' }]}  // **加粗** 标目标词
  sources={[{ src: crop, paper: '四年级 2025–2026 期末', question: '16' }]}      // 缩略图，点击放大（Lightbox）
  see={[{ term: '不规则复数', onClick: () => … }]}
  onOpen={() => openDrawer()}     // 点词头
>
  <UsageNote kind="mistake" …>…</UsageNote>   {/* 完整尺寸里放用法框 */}
</Entry>
```

标签 `kind`：`plain`、`mistake`（易错，玫红）、`new`（今年新考，主色）、`thin`（样本不足，虚线）。**每个标签必须带白话解释 `hint`**（悬停或键盘聚焦显示，Tooltip）。尺寸之间的取舍：compact 只显示词头、例词、标签、第一条释义（单行截断）；standard 显示第一条例句和第一张原卷截图；full 全部显示。

### 术语表接入

`src/shared/glossary.ts` 由功能代理创建，本阶段**没有创建**它。`glossaryData.ts` 用 `import.meta.glob('../../shared/glossary.ts', { eager: true })` 在构建时探测：文件存在就用，不存在就退回占位数据。接口约定：

```ts
export interface GlossaryItem { term: string; plain: string; example?: string }   // example 里可用 **加粗**
export const GLOSSARY: GlossaryItem[]                                              // 导出名不限：取第一个元素形如 GlossaryItem 的数组导出
export function lookup(term: string): GlossaryItem | undefined                    // 有就优先用
```

## 五、已知情况与缺口（第一阶段时的情况；铺开后的情况见第八节）

- 正式页面还是旧界面；**深色模式在旧页面里不完整**（页面里写死的 `#fff`、`#fafafa`、`#888` 等不会跟着变），所以 `ThemeProvider` 暂时没有挂到 `main.tsx`。第二阶段逐页迁移时一并解决。
- `StatsFilter.tsx` 的 `FilterBar` 自带行内样式，设计系统里只有一段 `[data-testid="filter-bar"]` 覆盖（仅在 `html.ewb-design` 下生效，实际没有用到）。第二阶段改用 `ScopeBar`，这段 CSS 可删。
- 没有引入 echarts，ECharts 主题只是导出，未做渲染验证；横条图和热力格用 DOM 组件。
- Gallery 里并排展示浅色 / 深色时，弹层（Tooltip、Popover、Modal）挂在 `body`，用的是当前全局主题的变量；单独切换到某个主题看弹层是准的，见 `m6-comp-overlay-*`。
- 样张里的「物主代词」和各大类的词条数是示意数字，页脚已注明；其余词条取自 `docs/体验报告/产出/tutor-考情分析报告.md`。

### 8.6 已知没做好的地方

- **最小窗口宽度实际是 900px**（`src/main/index.ts:74` 的 `minWidth`），产品文档写的是约 1100。所有页面在 1440、1100、900 三个宽度都截过图并检查了横向溢出：都没有溢出。统一口径要改 `src/main`，不在设计范围。
- **投屏大字用 CSS `zoom`**：整个界面（含弹窗）一起放大，窗口小时可用宽度按比例减小（1280×720 下相当于 1113×626）；Chromium 的 `zoom` 不是标准属性，将来换成 Electron 的页面缩放（需要主进程 / preload 配合）会更干净。
- **看板同比页签没有书眉**；报告页的书眉取当前报告的首尾小节标题。
- **队列页和报告页的等待条**没有直接用 `ThinkingBar`，而是复用它的 `.ewb-thinking__*` 样式类，因为主进程下发的是整句文案（`waitingText`）。`ThinkingBar` 已有整句文案参数，后续可以换成组件。
- **审核页框选叠加层**里「纸面」上的框用的是固定的主色浅色值（`#5B57D1`），不随主题变：原卷纸在深色模式下仍是白纸（`page-review.css`，`src/renderer` 里仅有的两处硬编码色）。
- **`ThumbIndex` 只能选中不能取消**（总览、看板里自己做了「再点一次回到全部」）。
- **145 个知识点的白话释义、例句**是功能代理写的，没有英语老师过目；样张里的词条文案只能算「示意」。
- **导出 PDF / Word / Markdown**由主进程生成，样式没有按 tokens 重做（浅色词典版、家长版不要密集表格仍是待办，需要协调会话安排）。
- **Windows 上没有看过**（字体回退、系统黑体、窗口控件都只在 Mac 上截图）。
- 样张 / 预览页（`/design`）里的 10 张原卷裁切图来自项目自带的合成样卷（`samples/`、体验报告产出），不含真实学校信息；但它们仍会打进安装包（在懒加载的预览页 chunk 里）。
