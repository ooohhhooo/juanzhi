# 安装指南

> 这份指南面向使用软件的老师。软件里「设置 → 关于 → 查看安装指南」显示的是同一份内容。软件不需要注册、不需要登录，试卷和分析结果都保存在你自己的电脑上。

## 一、先选对要下载的文件

文件名里的 1.2.0 是版本号，以你实际拿到的为准。

| 你的电脑 | 下载这个文件 |
|---|---|
| Mac，Apple 芯片（M1、M2、M3、M4 等） | Juanzhi-1.2.0-mac-arm64.dmg |
| Mac，Intel 处理器 | Juanzhi-1.2.0-mac-x64.dmg |
| Windows 10 / 11（64 位），推荐 | Juanzhi-1.2.0-win-x64-setup.exe（安装版） |
| Windows，不想安装或不能安装 | Juanzhi-1.2.0-win-x64-portable.exe（免安装版，双击就能用） |

**怎么看 Mac 是 Apple 芯片还是 Intel：** 点屏幕左上角的苹果图标，选「关于本机」。如果写着「芯片：Apple M…」就是 Apple 芯片；如果写着「处理器：Intel…」就是 Intel。选错不会损坏电脑：Intel 的包放在 Apple 芯片的 Mac 上通常也能打开（系统可能先提示安装 Rosetta，按提示装一下），但 Apple 芯片的包在 Intel 的 Mac 上打不开。打不开就换另一个文件。

**系统要求：** Mac 需要 macOS 13 或更新；Windows 需要 Windows 10（1809 以上）或 Windows 11。

## 二、Mac 的安装和第一次打开

1. 双击下载好的 dmg 文件，把里面的「卷知」拖到右边的「应用程序」文件夹。
2. 到「应用程序」里双击打开。因为软件没有购买苹果的开发者证书，也就没有经过苹果的「公证」，第一次打开时系统会拦一下，这是正常的，按下面的办法放行一次就好，以后不会再问。

**macOS 14 及更早的系统：**

1. 在「应用程序」里找到「卷知」，按住 Control 键点它（或者点鼠标右键），选「打开」。
2. 在弹出的提示框里再点一次「打开」。

**macOS 15（Sequoia）及更新的系统：** 这些系统取消了右键直接打开的办法，要到系统设置里放行。

1. 先正常双击打开一次，系统会提示「无法打开……」或「Apple 无法检查其是否包含恶意软件」，点「完成」（不要点「移到废纸篓」）。
2. 打开「系统设置」，点左边的「隐私与安全性」，往下滚到「安全性」一栏。
3. 看到「已阻止使用“卷知”」，点它旁边的「仍要打开」。
4. 输入电脑的开机密码（或用触控 ID 确认），再点「打开」。

**如果系统说「已损坏，无法打开」：** 这是下载文件被打上了隔离标记。打开「终端」程序，把下面这一行粘进去按回车，再重新打开软件：

```
xattr -cr /Applications/卷知.app
```

**钥匙串提示：** 第一次保存 AI 的密钥（API Key）时，系统可能弹出「卷知想要使用钥匙串中的机密信息」。输入开机密码，点「始终允许」即可。软件升级到新版本后可能再弹一次，处理方法相同。如果你点了「拒绝」，密钥就不会被记住，下次打开要重新填写，不影响其他功能。

## 三、Windows 的安装和第一次打开

**安装版（setup.exe）：**

1. 双击 setup.exe。Windows 会弹出蓝色的「Windows 已保护你的电脑」（SmartScreen）。这是因为软件没有购买代码签名证书，不代表有问题。点窗口里的「更多信息」，再点出现的「仍要运行」。
2. 安装向导是中文的。向导里会问「为谁安装」：选「仅为我」（默认选项）就不需要管理员密码，推荐这样；如果选「所有用户」，系统会要求输入管理员密码。
3. 接着可以选安装位置，默认是 C:\Users\你的用户名\AppData\Local\Programs\EnglishExamWorkbench，可以改。
4. 安装完成后，桌面和开始菜单里会自动出现「卷知」的快捷方式（桌面快捷方式是自动创建的，向导里没有勾选项），双击打开即可。

**免安装版（portable.exe）：** 把它放在任意文件夹（比如桌面）双击即可。第一次同样会遇到 SmartScreen，处理方法和上面一样。注意：免安装版每次启动都要先解压，会比安装版慢几秒。

**如果杀毒软件拦截了：** 在杀毒软件里把这个文件（或安装目录）加入信任，再重新运行。软件本身不会上传你的试卷。只有在你配置了 AI 服务并让它解析试卷时，才会把试卷文字，以及（只在配了视觉模型、需要读图时）扫描页的页面图片，发给你选择的 AI 服务商。

## 四、Windows 的「文字识别」（OCR）和中文语言包

图片、扫描件里的文字要靠电脑的文字识别功能读出来。Mac 自带，不用设置。Windows 用的是系统自带的识别引擎，**需要安装中文语言包里的 OCR 功能**：

1. 打开「设置」→「时间和语言」→「语言和区域」（Windows 10 里是「语言」）。
2. 点「添加语言」（Windows 10 是「添加首选的语言」），选「中文（简体，中国）」，点「下一页」。
3. 在可选功能里勾选「光学字符识别（OCR）」和「基本键入」，点「安装」。等它下载完（需要联网，可能要几分钟）。
4. 重新打开本软件。在「设置」页展开「管理员设置」，其中「文字识别（OCR）」卡片里应该显示「可用」和「Windows OCR（zh-Hans-CN）」。

**不装会怎么样：**

- 文字型 PDF 和 Word 文件不受影响，软件直接读取里面的文字，不需要 OCR。
- 图片和扫描件：如果电脑上只有英文的识别引擎，软件会在这份试卷上提示「OCR 使用 en-US 引擎，中文可能识别不全」；如果一个识别引擎也没有，这份卷子在列表里会标「OCR 失败」，打开详情页，这一页上方有红色提示「这一页的 OCR 没有成功：……」并写明原因（系统根本没有 OCR 功能时则显示「待 OCR（当前平台不支持）」，这时页面只保存了图片），不会假装识别成功。
- 已经在「设置 → 管理员设置 → AI 服务」里填了视觉模型的话，识别失败或质量太差的扫描页会交给视觉模型读图，所以也可以不装语言包，改用视觉模型。**注意：这时这些扫描页的页面图片会发送给你选择的 AI 服务商**（文字型 PDF 和 Word 不会发图片）。如果不想发图片，请不要填视觉模型，改装中文 OCR 语言包。

## 五、配置 AI（以 DeepSeek 为例）

软件的拆题、标注、年度对比分析和报告都需要一个大模型服务。你需要自己申请一个密钥（API Key），费用由服务商按用量收取，软件本身不收费。

1. 到 DeepSeek 开放平台（platform.deepseek.com）注册账号，充值少量金额，在「API Keys」里创建一个密钥，复制下来（它只会显示一次）。
2. 打开软件，进入「设置」→ 点「管理员设置」的「展开管理员设置」→「AI 服务」（这些是技术设置，一般由管理员做一次）。
3. 「服务商」选 DeepSeek，地址、文本模型和视觉模型会自动填好。模型名以服务商控制台为准，如果以后换了名字，在输入框里直接改即可。
4. 把密钥粘贴进「API Key」，点「保存」，再点「测试连接」。看到「连接成功」就配好了。
5. 回到「试卷库」，把试卷拖进窗口，软件会自动提取、解析，之后在「审核」里确认每道题的标注。

通义千问、豆包、Kimi、智谱也可以在服务商下拉框里直接选，步骤相同。密钥只保存在你自己的电脑上并加密，界面和日志里都不会显示；换电脑后需要重新填。

## 六、换电脑 / 备份数据

1. 在旧电脑上：「设置」页展开「管理员设置」，在「数据包（换电脑 / 备份）」卡片 →「导出数据包…」，保存成一个 .ewb.zip 文件。里面有全部试卷、题目标注和报告，但**没有 API 密钥**，也没有示例数据。
2. 把这个文件拷到新电脑（U 盘或网盘都行）。请像对待试卷原件一样保管它，它没有加密。
3. 在新电脑上装好软件，同一张卡片里点「导入数据包…」，选「合并」（和新电脑上已有的数据合在一起）或「覆盖」（用数据包里的数据替换，替换前软件会自动备份旧数据）。
4. 重新填写 AI 的密钥。

建议每学期结束、或者准备升级软件之前，先导出一份数据包当备份。

## 七、数据存在哪里

数据都在你自己的电脑上，没有云端。

| 系统 | 位置 |
|---|---|
| Mac | 个人文件夹 / 资源库 / Application Support / english-exam-workbench / workbench-data |
| Windows | C:\Users\你的用户名\AppData\Roaming\english-exam-workbench\workbench-data |

Mac 的「资源库」默认是隐藏的：在访达里点「前往」菜单，按住 Option 键，就会出现「资源库」。Windows 的 AppData 也是隐藏文件夹，在资源管理器地址栏里直接输入 %APPDATA%\english-exam-workbench 回车就能打开。

如果想把数据放在别的磁盘（比如移动硬盘），到「设置」页展开「管理员设置」，在「数据存储」卡片 →「更改数据目录…」，重启后生效。

软件的安装版和免安装版、Mac 的不同版本，用的都是同一个位置，所以升级和互相切换不会丢数据。

## 八、升级、卸载，以及要不要保留数据

**升级：** 下载新版本，用和第一次一样的方式安装即可（Mac 把新的应用拖进「应用程序」覆盖旧的；Windows 直接运行新的 setup.exe）。数据不受影响。升级前最好先导出一份数据包。

**卸载：**

- Mac：把「应用程序」里的「卷知」拖进废纸篓。
- Windows 安装版：「设置」→「应用」→「已安装的应用」（Windows 10 里叫「应用和功能」），找到「卷知」，点「卸载」。免安装版直接删除那个 exe 文件。

**卸载不会删除你的试卷和分析结果**，它们在上面「数据存在哪里」那个文件夹里，重新安装后会自动接上。如果你想彻底清除所有数据，卸载之后手动删除那个 english-exam-workbench 文件夹即可（删除前请确认已经导出了数据包，删除后无法恢复）。

## 九、常见问题

**打开软件后窗口一直是白的 / 打不开？** 先彻底关闭软件再重新打开一次。还不行，请记下系统版本、软件版本（「设置 → 关于」），告诉提供软件的人。

**提示「已经有一个窗口在运行」或点了没反应？** 软件只允许同时开一份，请先找到已经打开的那个窗口（Windows 看任务栏，Mac 看程序坞）。

**导入数据包时提示磁盘空间不足？** 解开数据包需要先在数据目录所在的磁盘上留出相当于数据包解压后大小的空间，外加一些余量。清理磁盘，或者先把数据目录换到空间更大的磁盘上，再重新导入。

**图片导入后文字乱七八糟？** 在 Windows 上多半是缺中文 OCR，见上面第四部分；在 Mac 上请确认图片是正的、清晰的（竖着拍的手机照片软件会自动转正）。

**Windows 上 HEIC 格式的手机照片导入失败？** 需要在微软商店安装「HEIF 图像扩展」，或者先把照片转成 JPG 再导入。

**想先试试软件，又不想动真实数据？** 「设置」页的「示例数据」卡片 →「加载示例数据」会放进 12 份模拟试卷，不会混进你真实数据的统计，随时可以点「清除示例数据」一键清除。

**更新后 Mac 又弹出钥匙串提示？** 这是正常的，输入开机密码并选「始终允许」即可，见上面第二部分。

## 十、命令行（给 Agent 或自己用，1.2.0 起）

卷知也可以在终端里用一行命令操作：导入试卷、看统计、生成和导出报告。Codex、Claude Code 这类能执行命令的助手也能直接调用。

1. 打开卷知，到「设置 → 管理员设置 → 命令行工具」，点「安装命令行工具」。装好后重新打开终端，输入 「juanzhi status」 就能用。
2. 使用命令行前**先关闭卷知窗口**（窗口和命令行不能同时用同一份数据）；AI 要先在窗口里配好（命令行不能设置密钥）。
3. 免安装版（portable）也能装，但每次运行要先解压、慢几秒，而且移动或删除免安装文件后短命令会失效；长期使用建议装安装版。

完整说明和每个命令见项目里的 「docs/命令行.md」；给 Agent 的说明书在 「skills/juanzhi/SKILL.md」。
