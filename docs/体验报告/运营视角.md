# 「英语校考分析工作台」1.0.0 体验报告（运营视角）

体验人：小学英语业务线运营（英语一般，不懂语法术语，不懂技术）
体验方式：用已安装的应用 + 真实 DeepSeek（deepseek-v4-pro），数据是复制的一份用户数据（已有 2024、2025 学年两份四年级期末卷）。截图在 `img/ops-*.png`，导出文件在 `产出/ops-*`。

## 一句话结论

**勉强能用。** 看板和导出的报告本身能拿到手、数字对得上，但：(1) 导入新卷子第一次、第二次都失败，只有第三次点才成功，而且界面没告诉我该怎么办；(2) 报告里全是知识点代码和统计词，老板要的结论放在最后，家长根本不能直接用，我得自己重写；(3) 手里只有 2~3 份卷子，所有「同比」结论软件自己都说「仅供参考」，我没法拿它跟老板拍板。

## AI 调用实际用量（都在限额内）

|---|---|---|

## 逐任务记录

### 任务 1：第一次打开，搞清楚这软件能干嘛

- **想做什么**：像第一次拿到软件的人，先弄明白它是干什么的。
- **实际怎么点**：打开后直接落在「试卷库」（一个空洞的表格+一个大虚线框）→ 点「总览」→ 点「口径说明」→ 点「设置」，一路往下翻到最底「关于」→ 点「查看安装指南」。
- **看到什么**：
  - 打开没有任何欢迎、引导、「三步上手」。（`ops-01-first-open.png`）
  - 「总览」有 4 个数字卡 + Top 10 + 「本学年新增知识点」，我能猜到大概是「统计考点」。（`ops-02-overview.png`）
  - 「口径说明」弹窗是一整面墙的文字，出现「向上汇总」「主/次知识点」「基线」「综合得分 = 出现率 × 分值占比 × (1 + 1.0 × 易错率)」。我读到第二屏就放弃了。（`ops-03-kouj.png`）
  - 「设置」页很长，里面有 OCR、AI 服务、提示词、知识点树，对我全是噪音。（`ops-04-settings.png`）
  - 「关于」里才有一句人话：「帮助教师分析试卷中的知识点分布和考频趋势」，藏在设置最底下。
  - 「安装指南」讲的是怎么下载、怎么过苹果的安全提示、怎么申请 API Key，是给「装软件的人」看的，不是告诉我「软件能帮我做什么」。（`ops-05-guide.png`）
- **卡点**：没有一个地方告诉我「你要做的事 = 导入卷子 → 确认 → 看板 → 生成报告」。大约花了 **5 分钟**东点西点才拼出流程。
- **看不懂的词**：口径、基线、向上汇总、出现率、OCR、API Key（见清单）。
- **完成？** 完成（靠猜）。

### 任务 2：导入新卷子（`g4-2025-page1.png`）

- **想做什么**：导入一张拍照的卷子，等处理完。
- **实际怎么点**：试卷库 →「导入试卷」→（选文件）→ 看到提示「已加入处理队列：1 份」→ 点「处理队列」看进度。（`ops-06`、`ops-07`）
- **看到什么**：
  1. 进度条走到「调用 AI 拆题与标注…」，约 1 分钟后变红「失败」：「AI 解析失败：第 1 页解析失败：模型输出被长度上限截断（内容太多），需要把这一批拆小。可以点击『重试』，或换一个更强的模型」。（`ops-09-queue-needs.png`）
  2. 我点「重试 AI 解析」，又等 1 分钟，**同样的错误**。（`ops-12-queue-after-retry.png`）
  3. 点进这份卷子的详情页，只看到图片和同一条红字，没有别的办法（不能手动录入、没有帮助）。（`ops-13-failed-detail.png`）
  4. 回来点按钮旁的小箭头，有 3 个选项：「重新 AI 解析（沿用已提取的文字）」「仅重新定位（沿用上次 AI 结果，不再调用模型）」「从头重试（重新提取文字再解析）」。我完全看不出区别，随手选了「从头重试」，**第三次成功了**。（`ops-10-retry-menu.png`、`ops-15-queue-after-retry2.png`）
  5. 成功后状态是「待审核」，卷子被自动命名为「2024-2025学年第二学期四年级英语期末试卷」，年级/学期/学年都是 AI 从卷头读出来的。
- **审核页**（`ops-17-review-detail.png`）：左边 25 道题的列表，中间是卷面图，右边是一堆字段（题型 `词汇分类（选出不同类）（VO_CLASS）`、知识点 `词汇分类（选出不同类）（VO.FORM.CLASSIFY）`、难度、易错、置信度 75%、「位置不确定」）。
  - 顶部黄条：「AI 备注：卷面标注满分100分，但本页可见四个大题合计仅55分，其余题目可能未在本图内。」这句我看得懂，也确实有用。
  - **25 道题全部显示「置信度 75%」+「位置不确定」**，但「需关注」又是 0。每道都一样的警告等于没警告。
  - 按运营水平我只能对着图核对：题号、题干、分值（10+20+10+15 = 55）都对；知识点（比如第 25 题标成「名词性物主代词」）我没法判断。
  - 右侧「题号」框太窄，第 25 题只显示「2」，容易误以为题号错了。
  - 我没有逐题点确认，直接点右上角「确认整份试卷」→ 弹窗「还有 25 道题没有逐题确认……」→「全部标为已确认并完成」。（`ops-19b-confirm-dialog.png`、`ops-20-after-confirm.png`）
- **一个大问题（软件没提醒）**：这张图其实是**已有的 2024-2025 学年卷子的第 1 页**。导入后试卷库里出现两份**标题一模一样**的「2024-2025学年…」（只有页数 1 / 2 不同），看板立刻变成「3 份试卷、97 题」，2024-2025 这一年被**重复计数**，同比的「基线 2 份」其实是同一套卷子的一半+一整套。软件的「重复导入」只按文件判断，这个情况它认不出来，也没有任何提示。（`ops-39-library-final.png`）
- **用时**：从点导入到能审核约 **6~7 分钟**（3 次各约 1 分钟的等待+我摸索的时间）；审核+确认约 3 分钟。
- **完成？** 完成，但前两次失败、第三次才成功，纯属运气；一个真运营在第二次失败后很可能就放弃了。

### 任务 3：看四年级考点分析，今年 vs 去年

- **想做什么**：用自己的话给老板讲「今年比去年有什么新变化、什么是重点难点」。
- **实际怎么点**：分析看板 → 「分布」→「同比」→「重难点」。（`ops-21-dashboard.png`、`ops-22-yoy.png`、`ops-23b-hard.png`）
- **看到什么**：
  - 「分布」：一张大色块图（面积=分值）+ 考频条 + 题型分布 + 难度分布 + 双向细目表。色块图直观，我能讲「功能交际、句型、写作占的分最多」。
  - 「同比」：四栏「新增 6 / 消失 5 / 上升 6 / 下降 0」。每条形如「比较级  基线 0/2 → 目标 1/1  出现率 0% → 100% · 引入年级 6」。我能读出「今年新考了比较级、一般过去时，去年考过的人称代词、be 动词今年没考」。
  - 但顶上黄条说：「样本有限：目标学年只有 1 份卷子，基线只有 2 份卷子（不足 5 份）……结论仅供参考」，所以这些「新增 / 消失」可能只是这份卷子刚好考没考到。老板如果追问「这是不是趋势」，我只能说不是。
  - 「引入年级 6」我以为是「这个考点几年级才开始学」，但看不出和我的判断有什么关系。「+50.0 个百分点」看得懂意思，但 1/2 到 1/1 就叫「上升 50」，数字本身有点吓人。
  - 「重难点」：一张表，「综合得分 0.1007」「易错率 9/9 · 100%」「平均难度 2.67」，我不知道 0.1007 是高还是低，也不知道它和「重点 / 难点」是什么关系；表里没有一句「所以重点是 X、难点是 Y」。
- **AI 年度变化分析（P2，2 次）**：
  - 第 1 次：等了约 **165 秒**，红框「生成失败：分析被输出长度上限截断，可以在设置 → AI 服务 → 高级里调大『输出上限』后重新生成。以下是中断前收到的内容，没有保存」。（`ops-25-yoy-ai.png`）
  - 按提示去设置→AI 服务→高级，把「输出长度上限（tokens）」从 8192 改成 16384，保存。（`ops-26-advanced.png`、`ops-27-saved-cap.png`）这一步对运营来说是**要靠猜**的：我不知道 token 是什么、该调到多少，只是随手翻了一倍。
  - 第 2 次：约 **190 秒**，成功。（`ops-29-yoy-ai-2.png`）
- **完成？** 能讲个大概，但是靠自己总结。我能讲的话是：「今年下学期卷比去年新考了比较级、一般过去时、语音辨析；去年的人称代词、be 动词今年没考；但只有一份今年的卷子，所以只能说『这份卷子是这样』，不能说趋势。名词复数（sheep、tomato）和介词固定搭配（time to / time for）是最容易错的。」

|---|---|---|
| **老板** | **3** | 数字都对得上看板，也有「样本偏小」的免责声明。但：(1) 最想看的「所以教研该抓什么、课程卖点是什么」放在**最后一节「教学建议」**，开头先给的是「样本概览」和一大张 10 行的代码表；(2) 表里是 `GR.NOUN` 这类代码，老板看不懂；(3) 「年度变化」只是把新增/消失的词全部罗列，没有一句「所以呢」；(4) 因为只有 1 份新卷，建议里写「不必据此刻意调整教学序列」——诚实，但老板拿不到决策。 |

### 老板最想看的结论在不在前面？

**不在。** 报告顺序是：样本概览 → 知识点分布 → 题型与分值 → 难度结构 → 重点与难点 → 易错点预警 → 年度变化 → 教学建议。真正有用的「教学建议」5 条在最后一页。**建议加一个顶部的「3 句话结论」**：①今年考什么、②最容易错什么、③建议怎么办。

2. 「重点与难点」：改成大白话，去掉代码。

### 有没有英语术语、统计术语、错误或空洞的话？

**统计术语**：出现率、分值占比、基线、目标学年、个百分点、综合得分、样本偏小（AI 报告里已不再出现「综合得分」，但看板里有）。

**英语术语**：名词性物主代词、第三人称单数、序数词、缩写、形容词用法等。

**错误（我核对出来的，也可能还有我没发现的）：**

1. **P2「同比 AI 解读」里把规则写反了**：「It's time for 后接动词，It's time to 后接名词」。正确的是 time **to + 动词**（It's time to get up），time **for + 名词**（It's time for lunch）。这是拿去给老师和家长讲会闹笑话的错误。**而同一次分析的报告「易错点预警」里写对了**（「time for + 名词，time to + 动词」），所以两处互相矛盾。
2. 报告「易错点预警」表里：
   - 「特殊疑问句」和「购物」两行的易错原因是**同一句话**（shoes 是复数 be 用 are；this skirt 是单数用 is），套话。
   - 「人称代词」一行里 sheep 那句话**重复了两遍**。
   - 「介词固定搭配」一行里「time to + 动词」写了两次（「time for + 名词，time to + 动词；time to + 动词原形」）。
   - 「词汇运用与变形」一行里「tomato 是单数，另两个是复数」是在解释「选不同类」的那道题，但归在了「词汇运用与变形」下面；P2 里还有一句「词汇分类里把单数 tomato 和复数 potatoes、carrots 视为同一类」，我看不出这个说法的依据。
3. 报告「知识点分布」里说「写作与书面表达……分值占比最高（23.5%）」，而「教学建议」里说「书面表达……分值占 11.8%」——两个数都没错（23.5% 是一级节点「写作与书面表达」，含 10 道连词成句；11.8% 是二级「书面表达」2 道作文），但同一份报告里一个说最高、一个说「虽只有 2 题」，运营要自己搞清楚为什么两个数不一样。
4. 「知识点分布」表只列了 10 行并说「其余略」，而「建议」里提到的「语音、时态」不在表里，读者找不到数据。

**空洞的话**：「保持常规训练」「语境化训练」「加强过程指导」「保温练习」；报告里反复出现的「样本偏小，仅供参考」。这些话 AI 说了没错，但对决策没帮助。

## 真实 AI 结果质量的观察

### 1. 解析得对不对（第 2 步导入的那页，25 道题）

- **对**：25 道题的数量、题号、大题分组、题干文字、选项都和卷面一致；分值（2 分/题 ×15 + 3 分/题 ×5…）也对；「AI 备注：本页可见四个大题合计仅 55 分」这种发现很有用；年级/学期/学年读得对（4 年级、下学期、2024-2025、期末）。
- **没法核对**：知识点标注（比如第 25 题标「名词性物主代词」）、难度、易错，我作为运营看不出对错。

## 改进建议

### 一、不改就用不下去

1. **导入失败后的出路**：失败后要么自动重试（同样的错误我连着遇到了两次），要么直接告诉运营「再点一次『重试』即可；多次失败请联系技术」。现在界面建议「换一个更强的模型」，运营做不到。三个重试选项请合成一个。
2. **P2 / 报告被截断时自动处理**：「输出长度上限」应该自动调大并重试，而不是让运营去设置里改一个叫 tokens 的数字。失败后「以下是中断前收到的内容，没有保存」也很浪费（等了 165 秒什么都没留下），至少应该保存。
3. **重复卷子识别**：导入时对比标题/学年/题目内容，发现「这张图像是已有的 2024-2025 卷第 1 页」要提示；试卷库里同名的两份至少要在标题旁标明页数或来源文件。否则所有「x/3」的统计都是错的。
4. **报告开头加「三句话结论」**，把「教学建议」前置；去掉代码列（`GR.NOUN` 等），报告里不出现内部编号。
5. **P2 里的英语规则错误**（time for / time to 写反）必须避免：至少让报告生成时对「易错点」加一道程序校验，或者把 P2 的教学建议标成「AI 草稿，请教研审核」。

### 二、明显更好用

6. **首次打开引导**：在「总览」放一个 3 步卡片（导入卷子 → 审核确认 → 看板/报告），并把「关于」里那句话放到首页。安装指南里增加「这个软件能做什么」。
7. **看板术语翻译**：出现率、基线、综合得分、引入年级、个百分点，改成人话；「重难点」页直接给「重点/难点」标签，别只给 0.1007。
8. **报告可读性分层**：导出时让我选「老板版 / 老师版 / 家长版」。至少家长版要有：大白话、少数据、一两个例子、能做的事。目前我写 200 字家长文字，软件一点忙都帮不上（只能从易错点里抄例子）。
9. **引用的题目**：直接显示题号 + 完整截图（不要截断，Q16 就被切了），不要有反引号；PDF/Markdown 同理。
10. **审核页**：置信度/位置不确定只在真有问题时显示；每道题都是「75%/位置不确定」等于没有信号；题号框加宽（第 25 题显示成「2」）；「AI 猜测」标签确认后要消失。
11. **报告标题和落款**：写上「四年级」「期末」「日期」；而不是「全部年级」。
12. **AI 等待**：显示「通常需要 2–3 分钟」，别让我对着转圈圈猜。

### 三、锦上添花

13. 看板色块图点进去后给一句话解释（这个考点是什么、举一个例子）。
14. 报告里的「其余略」表格别截断，或者提供「展开全部」。
15. 导出 PDF 成功时给一个明显的提示（我只在 Markdown 导出看到了提示）。
16. 总览里的「Top 10」在只有 2~3 份卷子时全是 100%，没有区分度；样本少时用「每份都考」之类的话替代。
17. 同比页在样本不足（<5 份）时折叠「新增/消失」的列表，只留一句「样本不足，暂不做比较」，避免老板过度解读。

## 附录：家长版文字（我自己整理，约 200 字）

> 四年级英语期末，孩子最容易丢分的有两类。第一类是名词复数：sheep（羊）单数复数一样，不能加 s；tomato（西红柿）要加 es，变成 tomatoes。第二类是固定搭配：时间到了要做某事，用 It's time **to** + 动作（It's time to get up，该起床了）；时间到了要吃饭、上课，用 It's time **for** + 名词（It's time for lunch）。另外，购物、问价钱（How much is this skirt?）、问天气，几乎每份卷子都会考。建议每天花 5 分钟，让孩子用英语说说身边的东西「有几个、多少钱、今天天气怎么样」，每周再写 5 句话（比如「我的上个周末」）。

**软件帮了多少 / 我自己改了多少：**

| 内容 | 来自软件 | 我自己做的 |
|---|---|---|
| sheep、tomato 的例子 | 报告「易错点预警」里有 | 加上中文意思，改成家长看得懂的写法 |
| time to / time for | 报告里有（但 P2 里写反了） | **我按英语常识核对后改对**，加了例句 |
| 购物、天气「几乎每份卷子都考」 | 看板：购物、谈论天气 3/3 份 | 改成口语；没有写「出现率 100%」 |

| 哪些该写、哪些不该写（比如不提「样本只有 3 份」的统计问题，也不提难度/易错率的数字） | 无 | 全靠我自己判断 |

**结论**：软件给了我**素材**（具体易错词和例句），但**没有给任何可以直接用的家长版文字**，改写、取舍、语气全部是我自己做的；如果当时没有英语常识，我会把 P2 里写反的 time for / time to 直接抄给家长。
