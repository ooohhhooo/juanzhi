**结论**：AI 估计的易错点集中在名词复数、介词固定搭配、词汇运用与变形、语音辨析等，其中名词复数和介词固定搭配易错题数最多。

| 代码 | 名称 | 易错原因 |

| FN.SHOP | 购物 | shoes 是复数，be 动词用 are；this skirt 是单数，用 is |

## 年度变化

**结论**：目标学年出现比较级、一般过去时等新增知识点，人称代词、be 动词等消失，补全对话与情境应答等出现率上升。  
**依据**：新增：比较级（目标 1/1 份）、一般过去时（目标 1/1 份）、动词形式变化（目标 1/1 份）、have / has（目标 1/1 份）、字母与字母组合发音（目标 1/1 份）、推理判断（目标 1/1 份）。消失：人称代词（基线 2/2 份）、be 动词（基线 2/2 份）、词汇运用与变形（基线 2/2 份）、询问时间与日期（基线 1/2 份）、形容词用法（基线 1/2 份）。明显上升：补全对话与情境应答（1/2 → 1/1 份，+50.0 个百分点）、物主代词（1/2 → 1/1 份，+50.0 个百分点）、细节理解（1/2 → 1/1 份，+50.0 个百分点）、主题词汇（1/2 → 1/1 份，+50.0 个百分点）、书面表达（1/2 → 1/1 份，+50.0 个百分点）、连词成句（1/2 → 1/1 份，+50.0 个百分点）。明显下降：无。  
**建议**：年度变化样本仅 1 份目标卷，新增和消失可能是个例，不必据此刻意调整教学序列；可对新增语法点做小范围前测，确认学生真实起点。

## 教学建议

1. 优先巩固功能交际、句型、词汇等出现率高且题数多的知识点，确保基础题得分。（知识点分布）  
2. 专项突破名词复数和介词固定搭配两个易错点，用样卷原题做当堂诊断，不孤立讲规则。（易错点预警）  
3. 书面表达虽只有 2 题，但分值占 11.8%、平均难度 4.5，需加强写作过程指导。（题型与分值、难度结构）  
4. 对年度变化新增的语法点（如一般过去时、比较级）做小范围检测，验证是否为本年级真实薄弱点。（年度变化）  
5. 单项选择和补全对话占分高，保持语境化训练，关注情境应答而非机械选择。（题型与分值）
