评价对象：`产出/tutor-parent-wechat.txt`（老师贴进微信群的原文），对照 `产出/tutor-parent.md`（应用内显示版）。

**打分：3 / 5**（上一轮 1.0.0 家长版只有 1 分，这版明显能用了，但离 4 分还差一点）。

## 0. 我读到的原文（微信里的样子）

> 四年级 下学期 2024–2026学年 期末 考情分析报告（家长版）· 2026-10-27
>
> 1. 一个变多个，词尾怎么变：tomato 要加 -es；sheep 一只和很多只都是 sheep，不加 -s。在家拿西红柿和绵羊图卡问“一个、很多个”，让孩子说并写。例句：I see two dogs. 我看到两只狗。
> 2. 到点该做什么，说法要分清：time for 接早饭、午饭；time to 接上床睡觉这类动作。在家每到吃饭、睡觉前问“到做什么的时间了”，让孩子说一句。例句：It's time for lunch. 到午饭时间了。
> 3. 问价钱，看清是一条还是一双：鞋子两只用 are，短裙一条用 is。在家拿鞋和短裙问“多少钱”，孩子先选 are 还是 is。例句：Those are my shoes. 那些是我的鞋子。
>
> 每天几分钟，进步看得见。

## 1. 孩子要注意什么？我自己的话复述

- 第 1 条：英文里东西多了，写法要变。好像西红柿后面要加个什么，绵羊不用变。我不确定“-es”是加在哪儿，也不知道还有哪些词也这样。
- 第 2 条：说“到吃饭时间了”和“到睡觉时间了”，英文里有两个小词不一样，一个接吃的，一个接动作。我记不住哪个是哪个，但知道有两个。
- 第 3 条：问鞋子多少钱和问裙子多少钱，用的词不一样，一双鞋用一个，一条裙子用另一个。

总的感觉：我大概知道有 3 个小点，比上一版强很多。但我没法一眼说清“考试是怎么考的”：是选择题、填空，还是看图说话？这个原文没说。

## 2. 在家能做什么？

- 每一条后面都有一句“在家……”，这点很好，是我最需要的。
- 第 2 条最容易做：吃饭、睡觉前顺口问一句，不用准备东西。
- 第 3 条也行：鞋和裙子家里就有。
- 第 1 条有点麻烦：“西红柿和绵羊图卡”，我得去找或画图卡。西红柿家里能找到，绵羊就得上网搜图打印。不知道不做图卡行不行。
- 我自己英语不行，我问“多少钱”，孩子说 are 还是 is，**我不知道他说得对不对**。没有告诉我答案是什么。第 2 条同理：孩子说一句，我没法判断对错。
- 总体：能照着做的有两条半，但“我怎么知道孩子做对了”没交代。

## 3. 看不懂的词，逐个列出

| 位置 | 词 | 我的反应 |
|---|---|---|
| 第 1 条标题 | **词尾** | 看不懂，跳过。“怎么变”也只能猜 |
| 第 1 条 | **-es**、**-s** | 前面带个横线，像减号，不知道是加在后面的字母。“tomato 要加 -es”读不顺 |
| 第 1 条 | “sheep 一只和很多只都是 sheep” | 能懂，这句最好懂 |
| 第 2 条 | **time for / time to 接……** | “接”是什么意思？是“后面跟着”吗？读半天才猜出来。“time to 接上床睡觉这类动作”还要想一下 |
| 第 3 条 | **are / is** | 隐约记得是“是”，但不知道什么时候用哪个。不过这里给了“两只用 are、一条用 is”，勉强能懂 |
| 标题 | **考情分析报告**、**期末**、**2024–2026学年** | “考情分析”像公文。“2024–2026学年”是两年？我家孩子明明只上四年级下学期 |
| 标题 | **（家长版）** | 老师发给家长，还写“家长版”，有点奇怪，像系统导出的文件名 |
| 全文 | 百分比 | 没有，这点很好 |

英文例词有没有中文解释：
- tomato：正文写了“西红柿”，但在“图卡”那句里才出现，读到 tomato 时我还不知道是什么，要往后读。
- sheep：后面有“绵羊”，同上。
- time for / time to：没有中文，“早饭、午饭”算半个解释。
- 三个例句：都有中文，这点好。
- 但是 **are / is、shoes、skirt** 的中文是分散的，我要来回对。

**还有一个让我困惑的地方：例句和上面讲的点对不上。**
- 第 1 条讲的是 tomato 加 -es、sheep 不变，例句却是 “I see two dogs”（dogs 只加 -s），这个例句没有展示老师刚刚讲的任何一个点，我看了反而疑惑：dogs 加 s，那 sheep 为什么不加？
- 第 3 条讲的是“问价钱”，例句却是 “Those are my shoes.”，根本没有价钱，也没有 how much。我读到这里以为选错了例子。

## 4. 语气

- 优点：没吓人，没有“错误率”“丢分”这种词，没有焦虑感。三点都是“在家怎么练”，是正面的。
- 缺点一：**没有一句话告诉我“要不要担心”**。我读完不知道孩子是“问题不大”还是“有点危险”。这是我最关心的三件事之一，原文完全没答。
- 缺点二：像一份教案，不像老师说话。没有“各位家长好”，没有“孩子”两个字，没有“您”。老师在群里发消息，不会不打招呼。
- 缺点三：结尾“每天几分钟，进步看得见。”像培训班广告，特别是前面没有任何铺垫，一下子冒出这么一句，反而让我觉得有点假。
- 小标题（“到点该做什么，说法要分清”“看清是一条还是一双”）挺好，像老师口头提醒的。

## 5. 长度

- 软件提示 381 字。我用工具数过：连标点和空格 381，去掉空白约 340，**确实超了 300 字的目标**，超出约 80 字。
- 在微信里读累不累：三条各 4 行左右，单条不算长，不太累。但每条都是“知识点 + 在家做法 + 例句”三段挤在一个大段落里，没有换行分开，**手机屏幕上一条就是一大坨字**，眼睛找不到重点。
- 最长的是第 1 条（约 95 字）。要是我是家长，会在读到“例句”之前就想划走。

## 6. 排版（贴进微信后）

- 编号 “1. 2. 3.”：微信里会正常显示，没问题。
- 条与条之间没有空行，三条挨在一起，读起来比较挤。标题和结尾之间有空行，OK。
- 标题行很长（“四年级 下学期 2024–2026学年 期末 考情分析报告（家长版）· 2026-10-27”），在手机上会折成两行，中间的 `·`、`–`（短横）看着像乱码，有点不整齐。
- “-es”“-s”前面的横线，和中文标点挨在一起，容易看成减号，也容易被微信当成列表符号，建议换成“加 es”。
- 中文和英文夹在同一行，没有加空格或括号，例如“例句：I see two dogs. 我看到两只狗。”，读着有点糊。把中文放进括号会清楚一些。
- 没看到乱码、没有残留的 `**` 或 `#`，这点好（说明纯文本版处理对了）。

## 7. 打分与理由

**3 分（满分 5）。**

加分的地方：
- 没有任何统计词、百分比、“正确率”，不吓人。（上一版最大的问题解决了）
- 每一条都有“在家怎么做”，不是只讲知识点。
- 有中文解释的例句，有小标题。
- 微信纯文本，没有乱码。

扣分的地方（离 4 分的差距）：
1. **还剩 3 个看不懂的词**：“词尾”“-es / -s”“time for / time to 接”。目标是通篇无术语，这里没做到。
2. **例句和知识点对不上**（第 1、3 条），家长会困惑。
3. **没说要不要担心**，我最想知道的三件事之一没回答。
4. **超长 80 字**，而且每条挤成一大段。
5. **没有老师的口吻**：没有称呼，没有孩子，结尾像广告。
6. **家长没法判断孩子说得对不对**：没给答案。

## 离 5 分还差什么

要到 5 分，我需要：
1. 去掉“词尾”“-es”“接”，换成“后面加 es”“后面跟”这种说法。
2. 例句必须就是知识点本身：第 1 条用 tomatoes / sheep，第 3 条用 How much are these shoes?。
3. 开头一句“各位家长好”，结尾一句“整体不用担心”，让我知道要不要紧。
4. 每条后面给一个标准答案，让我这个不懂英语的人能对。
5. 控制在 300 字内，每条分 2–3 行，条与条之间空一行。
6. 去掉广告式结尾和“家长版”“考情分析报告”这种标题。

### 2. 读完后，我自己的话

**孩子要注意什么：**
- 西红柿变成两个时，英文要多写 es（tomatoes），别只写 tomato。
- 说"到……时间了"，有两个小词 time for 和 time to，别混。吃饭用 time for。
- can not 分开写的两个词，合起来写要写成 can't，不能乱写。

**我在家打算怎么做：**
- 吃饭时顺口问："两个西红柿英语怎么说？"孩子说 two tomatoes 就行，不是就告诉他加 es。
- 问"吃早饭时间用 time for 还是 time to？"孩子答 time for 就对。
- 让孩子把 can not 合起来写一次，写出 can't 就对。
- 每条就一两分钟，不用准备东西，不用上网找图。这点比上一版的"图卡"轻松很多。
- 整体不担心。
