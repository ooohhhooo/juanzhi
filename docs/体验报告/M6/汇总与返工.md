## 返工清单

### R1 家长版（家长 3 分 → 目标 ≥4）
1. 老师口吻：开头「各位家长好」，结尾一句回答「要不要担心」；去掉「期末 考情分析报告（家长版）」式标题和「2024–2026学年」，去掉广告腔（「进步看得见」）。
2. 例句必须和这一条讲的知识点对上（tomato/sheep 那条配了 dogs、问价那条配了 Those are my shoes）——程序校验例句里出现该条的关键词，不对就换成知识点自带的例句。
3. 去掉「词尾」「-es / -s」「接」这类写法，改成「后面加 es」「后面跟」；每条「在家做」给出标准答案，让不懂英语的家长能判断对错；不要求打印图卡这类麻烦事。
4. 字数口径统一：界面显示的字数 = 复制到微信的字数，≤300；条与条之间空一行。

### R2 老板版（老板 3.5 → 目标 ≥4）
1. 三句话结论改成决策语言，第一句带样本：「基于 2 份卷子，方向参考：下学期先投 A、B、C 三块，其他不动」。
2. 样本警告压成标题下一行，门槛统一（不要同时出现「不足 5 份」「少于 3 份」），不出现「基线学年」「目标学年」「出现率」「程序判定」。
3. 自相矛盾检查：已声明「不下难点结论」时，正文不能写「可能全部易错」这类难点结论。
4. 风险提示写成动作：补几份卷子、用学生真实得分校对、之后再对外宣传。
5. 「课程卖点」改成可以对外说的话，每条标「现在能说」或「等有真实得分再说」。
6. 已核对的报告 PDF/Word 页脚不再写「AI 草稿」，改成数据口径（几份卷子、哪几个学年）。

### R3 事实核对和报告质量
1. 误报：「孩子容易给 sheep 加 -s」「sheep 不加 -s」是对的却被标「矛盾」（老师版）——否定和「容易错成」的描述不能当断言。
2. 核对条展开后句子是断的（「结合 、 做对比练习」）；同一条黄条出现两次；老板版里同一说法没被标（口径不一致）。
3. 程序写死的句子里还有「基线学年」「目标学年」「出现率」；完整版有重复句（`time to + 动词；time to + 动词原形`）。
4. 老师版：截图插在句子中间（应放在段落后）；例句和考点不配套（语音配 fish/fox）；分值最高的「连词成句」「书面表达」没写——证据包要覆盖分值最高的题型。
5. 复制到微信：小标题被编成「1.」，后面条目接着编 2、3、4。
6. Markdown 开头写「截图在同名文件夹里」，但没有图时也写了。

### R4 内部代码和截图
1. 内部代码还会漏出来：审核页第 30 题主知识点显示 `RD.INFER.OPINION`，提示里有 `GR.PRON.DEMO`。
2. 引用截图：第 20、31、33 题仍有残字、带出邻题题号或右边被切。

### R5 界面
1. 看板「重难点」里蓝色考点名像链接却点不开，要能打开词条抽屉；抽屉里的 AI 分析要只讲这一个考点（现在生成整篇年度分析，等 111 秒只得到一句「没单独讨论」）。
2. 疑似重复卷：试卷库状态栏、「最近导入」不能只写「已完成」，要写「疑似重复 · 没计入统计」；审核页和确认弹窗也要提一句。
3. 「我已核对」对运营：说明这一步应由懂英语的老师做，给运营一个「交给老师核对」的出口（比如复制核对清单）。
4. 「投屏大字」四个字点了没反应（只能点开关）。
5. 审美：试卷库首屏被引导卡占满；黄色提示条叠太多（同一警告在应用、报告开头、风险节出现三次）；报告页留白大、老师版正文版面乱；设置页平淡。
