# 「英语校考分析工作台」1.1.0（M6）体验报告（运营视角）

体验人：小学英语业务线运营（英语一般，不懂语法术语，不懂技术）
体验方式：用 out/ 里构建好的 1.1.0 应用 + 真实 DeepSeek（文本 deepseek-v4-pro，看图 deepseek-flash）。数据是复制的一份底库（已有 2024-2025、2025-2026 两份四年级期末卷，各 36 题）。全程点界面；只有「选文件」「选保存位置」两个系统对话框用脚本代替（拖文件进虚线框、指定保存路径）。没有弹钥匙串窗口。截图在 `img/ops-*.png`，导出文件在 `产出/ops-*`。

## 一句话结论

**流畅。** 打开就有「我是运营」三步路线；导入那张重复的卷子，软件认出来了、没把它算进统计、在三个页面都提醒了我；报告点一下就出，老板版我拿来几乎不用改，Word / PDF / 复制到微信都能直接用；界面也不丑了。

扣分的地方不在「卡」，而在「还差一口气」：(1) 疑似重复的卷子在试卷库和「最近导入」里还写着「已完成」，审核页和确认弹窗一个字没提，我是靠看板上的黄条才明白；(2) 「我已核对」要我判断英语规则对不对，我判断不了，也没说该找谁；(3) 这次真实 AI 3 次全是一次成功，所以「失败了怎么办」「自动重试」我**没有碰到，没法验证**；家长版我也没生成（预算只给了老板版和完整版），家长版里有没有术语我没法替它打包票。

## 逐任务记录

### 任务 1：第一次打开，选角色，搞清楚这软件干嘛

- **想做什么**：像第一次拿到软件的人，先弄明白它是干嘛的。
- **怎么点的**：打开 → 看到试卷库顶上的卡片「第一次用？选你的角色，三步上手」→ 点「我是辅导老师」看了一眼 → 点回「我是运营」→ 点「使用说明」。
- **看到什么**：
  - 落地页还是「试卷库」，但上面多了一张三步卡片：1 导入卷子 → 2 等 AI 整理、请老师确认 → 3 看分析、生成报告，每步右边有个直达按钮（「去试卷库」「看处理队列」「去生成报告」）。选「我是运营」时的那句话「把校内考试卷变成给老板和家长看的材料」就是我想知道的。（`ops-01-first-open.png`、`ops-01c-ops-route.png`、`ops-01b-teacher-route.png`）
  - 「使用说明」第一段就是人话：「把学校的英语考试卷交给它，它会读出每道题、标上"考什么"，再统计出今年考什么、哪里容易错、和去年比有什么变化，最后写成给老板、家长、老师看的报告」；下面是运营的 5 步，每步 1–2 句。还有「卷子太少时别下结论」这种我真用得上的提醒。（`ops-01d-guide.png`）
- **卡点**：基本没有。**大约 1 分钟**就知道流程了（上一轮是 5 分钟东点西点）。小毛病：说明里写「分析看板里有四个页签」，后面只列了三个（分布、同比、重难点）；三步卡片占了半屏，真正的试卷表格被挤到屏幕下面，要滚动才看得到。
- **完成？** 完成，一次到位。

### 任务 2：总览，今年考什么、最该关注什么

- **想做什么**：10 秒内知道「今年考什么、最要盯什么」。
- **怎么点的**：点左边图标栏「总览」→ 往下滚 → 鼠标放到「样本不足」上 → 点「怎么算的」。（`ops-02-overview.png`，`ops-02-overview-s1~s5.png`，`ops-02b-tooltip-sample.png`，`ops-02c-howcalc.png`）
- **看到什么**：
  - 大标题一句话：「这 2 份卷子共 72 道题，考得最多的是 连词成句 和 细节理解」；右上角一个红框「易错　最容易丢分：名词复数」。这两句我可以直接拿去开会说。
  - 下面是「词条」卡片：每个知识点一张，写着名称（连词成句）、3 个英文例词、所属大类（写作）、「两份卷子都考了」「10 道题」「易错」、一句白话（把乱序的词排成一个正确的句子）、一个中英对照例句（Put the words in order. 把单词按顺序排好。）、一张原卷截图。**我看得懂**，而且头一次不用再去查「GR.NOUN」是什么。
  - 样本少时，原来全是 100% 的「Top 10」变成了两组：「每份都考（2 份都有）」和「只考了一份」，还有一句「卷子只有 1–2 份，排名没有意义」。这个处理我很喜欢。
  - 「样本不足」这个词下面有虚线，放上去弹出「用来比的卷子少于 3 份，一两份卷子的差别就能造成"新增""消失"，所以先不下结论。多导入几份再看」。「今年新出现的知识点」那一块默认折叠，写着「样本不足，暂不比较（8 个，点开仍要查看）」。
  - 「怎么算的」弹窗是「三句话看懂」，详细的折叠起来了。上一轮那面文字墙没了。
- **卡点**：
  - 「今年新出现」那一块上面叠了两条黄色「注意」，意思差不多（样本有限 / 样本不足），读着有点重复。
  - 右上角「连词成句 — 动词形式变化」是啥意思？每个页面都变。我猜是词典页眉的装饰（本页第一个词和最后一个词），对我没用，甚至会让我以为是「范围」。
  - 原卷截图有的上下边多切进了相邻题的一点边（第 31 题那张末尾多出「32.」半个字），看着像没裁干净。
- **词条、白话、例句看得懂吗**：看得懂。「名词复数 一个变多个，词尾怎么变」「介词固定搭配 固定搭配：time for、look at 等」，我都能转述。「样本不足」提示清楚。
- **完成？** 完成。

### 任务 3：导入疑似重复卷（`g4-2025-page1.png`，真实 AI #1）

- **想做什么**：导入这张图片，看软件提不提醒我它其实是已有卷子的第 1 页。
- **怎么点的**：试卷库 → 把图片拖进虚线框（提示「已加入处理队列：1 份」）→ 点「队列」看进度 → 完成后回试卷库 → 点标题旁的「疑似重复」→ 点「去审核」→ 点「确认整份试卷」→ 点「全部标为已确认并完成」→ 回总览、看板看数字。
- **看到什么**：
  1. **等待体验**：队列页显示四步进度（提取文字 → 拆题与标注 → 定位题目 → 保存入库）、一个「AI 解析中」小标签、「**AI 正在思考 · 已用 6 秒（通常 2–3 分钟）**」和一条进度条，每 5 秒数字往上走。我知道它没死、知道大概多久。（`ops-03c-queue-thinking1~3.png`）这次约 1 分钟结束，没失败。
  2. **提醒**：试卷库里新卷子标题旁多了一个深色小标签「疑似重复」，状态「待审核」。点它弹出气泡：「疑似重复：像是《2024-2025学年第二学期四年级英语期末试卷》的一部分（77% 的题在那份卷子里也有）。默认不计入统计，免得同一份卷子被算两次。被标出来的也可能是旧卷（后来又导入了更完整的一份）」，底下两个按钮「**确实是新卷，计入统计**」和「**删除这份**」。**我知道该点什么**：这是重复，点「删除这份」。（`ops-03e-library-after.png`、`ops-03g-dup-tag-click.png`）
  3. 我装作不懂，直接去审核页点了「确认整份试卷」。审核页顶上没有任何重复提示，弹窗只说「还有 25 道题没有逐题确认」，我点了确认，状态变成「已完成」，标签「疑似重复」还在。（`ops-03h-dup-review.png`、`ops-03i-dup-confirm-dialog.png`、`ops-03k-library-after-confirm.png`）
  4. **看板上有补救**：总览、看板的三个页签顶上都有一条黄条「有 1 份疑似重复的卷子没有计入（像是已有卷子的一部分；到试卷库或处理队列里选"确实是新卷，计入统计"或删除…）」，数字仍然是「2 份卷子、72 题」——没被重复计算。（`ops-03l-overview-after-dup.png`、`ops-04-dashboard.png`）
- **卡点**：
  - 提醒主要靠那个小标签，**没点开我不会知道这是干嘛的**；列表里状态栏写「已完成」，我容易当成「已经算进去了」。
  - 审核页和「确认整份试卷」弹窗对重复只字不提——我是最需要被拦一下的人。
  - 总览底部「最近导入」里这张 25 题的重复卷子和正常卷子一样排着，写「已完成」，上面写「试卷 2 份」，下面列了 3 行，容易让人迷糊。
  - 「怎么算的」里说「只统计老师确认过的卷子」，而我确认了它仍然不被统计。两句话在我看来冲突（其实是被「疑似重复」单独挡了）。
- **完成？** 完成。软件认出了重复、没算进去、告诉了我；只是主要信号靠小标签，不够显眼。

### 任务 4：看板，知识点分布和同比

- **想做什么**：用自己的话给老板讲「今年比去年有什么变化、什么是重点难点」。
- **怎么点的**：看板 →「分布」→「同比」→「重难点」→ 点「修改范围」→ 点第一行的「＋」展开。
- **看到什么**：
  - 「分布」：顶上是黄条（重复卷）+ 4 个小数字胶囊（试卷 2 份、题目 72 道、总分合计 200、分值覆盖 72/72 题）；「哪些知识点考得多」因为只有 2 份卷子，**软件自己说「没有信息量，所以不画条形」**，改成「每份都考 13 个 / 1/2 份卷子考到 2 个」。下面是一个方块大图（面积=分值）、题型分布、难度分布（1–5 星）、知识点×题型表（原来叫「双向细目表」）。（`ops-04-dashboard.png`、`ops-04-dash-dist-s1~s3.png`）
  - 「同比」：开头 3 条黄条——重复卷、样本有限、**样本不足，暂不比较（用来比的卷子少于 3 份）**，下面「今年新考 8 / 今年没考 4 / 考得更多 0 / 考得更少 0」默认折叠，点「仍要查看」才展开。不再有「+50.0 个百分点」这种吓人的数字。（`ops-04b-yoy.png`）
  - 「重难点」：表里每个知识点后面有「重点 / 又重又难 / 个例 / 一般」标签，「两份卷子都考了」「占总分 15%」「10 道里估计 1 道容易错」「中等偏易」。展开「＋」能看到「为什么容易错」和原卷例题。比如「名词复数 又重又难」、「书面表达 又重又难」。（`ops-04c-hard.png`、`ops-04e-hard-expanded.png`）
- **看得懂吗**：**比上次好太多。** 以前「基线 0/2 → 目标 1/1 出现率 0% → 100%」，现在「去年没考，今年考了」「两份卷子都考了」「10 道里估计 1 道容易错」。我知道「重点」是考得多、分值高，「难点」是容易错/难。
- **卡点**：
  - 同比页顶上叠了 3 条黄条（重复卷、样本有限、样本不足），一屏下去几乎都是「注意」。
  - 方块大图每块都是同一种紫色（因为都是「100% 的卷子考了」），除了大小就没有别的信息。
  - 还残留几个词：「二级知识点 / 三级知识点」「分值覆盖 72/72 题」「总分合计 200（仅含有分值的题）」「只比同一学期」，我只能猜。有「怎么算的」可以点，但这几个词旁边没有解释。
  - 「修改范围」点开后筛选区一直撑着，要再点「收起」。
- **完成？** 完成。我能讲：「这两份卷子里，写作占三成分值、阅读一成半；名词复数、介词固定搭配最容易错；但只有两份，不能说是趋势。」

### 任务 5：生成老板版（真实 AI #2），导出 Word / PDF

- **想做什么**：生成一份能直接给老板看的报告，并导出三种格式。
- **怎么点的**：报告 → 点「老板版」卡片 → 点「生成老板版」→ 等 → 点「导出 Word」「导出 PDF」「导出 Markdown」（每次出保存路径对话框，用脚本代指定到 `产出/ops-boss.*`）。另外点了「怎么算的？要花钱吗？」、「我已核对」、「复制到微信」。
- **等待体验**（`ops-05c-boss-wait1~3.png`）：按钮变灰，出现一条条「处理中　AI 正在准备 → AI 正在思考 · 已用 40 秒（通常 2–3 分钟）→ AI 正在写 · 已用 66 秒」+ 进度条 + 「取消生成」，下面卡片「正在生成：老板版　AI 在认真写，请稍等，不需要操作」。AI 开始写之后，文字会逐步出现在页面上。**71 秒**完成，没有任何错误提示。
- **成品**（`ops-05d-boss-done.png`、`ops-05e-boss-report-1~3.png`、`产出/ops-boss.md`）：标题「**四年级 下学期 2024–2026学年 期末 考情分析报告（老板版）· 2026-10-27**」（上一轮是「全部年级」）。结构：三句话结论（今年考什么 / 最容易丢分在哪 / 建议怎么做）→ 教研重点与课程卖点 → 风险提示。没有代码、没有表格。
  - 我能直接拿去用的：三句话结论，一句话说得清。
  - 数字我对了看板：写作与书面表达占「三成」（60/200）、阅读「一成半」（30/200）、单项选择「两成」（40/200）、名词复数 6 道题 6 道估计易错——都对得上。
  - 「风险提示」讲清楚了「只有 2 份卷子，不能当规律」「AI 估计的易错点不是学生实际得分」。
- **导出**：
  - **提示很明显**：导出后页面上出现一个绿色浮窗「已导出 Word」，下面还有一个「已导出」卡片，写着完整路径 + 「在文件夹里显示」按钮。（`ops-05f-boss-export-docx.png`）上一轮 PDF 导出没有提示的问题解决了。
  - `ops-boss.docx`：4 KB，一页，标题 / 小标题 / 编号 / 圆点都在，中文正常；用系统预览看过。（`ops-05h-boss-docx-preview.png`）
  - `ops-boss.pdf`：2 页，版面干净，标题 + 黄底说明块 + 小标题 + 圆点列表 + 页码。（`ops-05g-boss-pdf-p1.png`）
  - `ops-boss.md`：没有反引号、没有乱码；开头一行 HTML 注释写着「引用的题目截图在同名文件夹「ops-boss」里」，**但老板版根本没有截图，也就没有这个文件夹**（说明和实际不一致，小毛病）。
- **「复制到微信」**：点了就出「已复制 1088 字，可以直接粘贴到微信」（`ops-09d-copy-wechat.png`）。我去读了剪贴板：是纯文字，标题、三句话、条目都在。小问题：「教研重点：」这个小标题被编号成了「1.」，后面的条目接着编成 2、3、4、5……，粘到微信里会觉得「教研重点」也是一条。
- **「我已核对」**：点了会弹窗「确认你已经核对过这份报告？……请至少看一遍：讲英语规则的句子对不对、例句有没有错」（`ops-09c-boss-confirmed.png`）。我**没有点确认**，因为我没法判断英语规则对不对；也没有说「找谁核对」。老板版不核对也能复制/导出，所以没挡住我，但家长版会挡（按说明）。
- **报告里还是有点难的词**：「出现率」（在说明里）、「目标学年和基线学年各只有 1 份」、「序数词 third 前要加 the」。老板大概看得懂前两句的意思，但「基线学年」这种词我不会写给老板。
- **完成？** 完成，一次成功。

### 任务 6：生成完整数据版（真实 AI #3），存 ops-full.md

- **怎么点的**：报告 → 点「完整数据版」→「生成完整数据版」→ 等 → 导出三种格式（`产出/ops-full.md/.docx/.pdf`，md 旁边有 `ops-full/` 文件夹，14 张题目截图）。
- **等待体验**：同上，「AI 正在思考 · 已用 101 秒」，到 163 秒变成「AI 正在写」，**178 秒**完成。这次等了快 3 分钟，但页面一直在报数，我没有「是不是卡死了」的感觉。（`ops-06b-full-wait1~4.png`）
- **成品**（`ops-06d-full-done.png`、`ops-06e-full-report-1~8.png`）：标题同样带「四年级 下学期 2024–2026学年 期末」；章节是样本概览 → 知识点分布 → 题型与分值 → 难度结构 → 重点与难点 → 易错点预警（表格）→ 教学建议。每节都是「结论 / 依据 / 建议」三行，数字我都对了看板：72 题、30%、20 题 40 分 20%、难度 35/31/3/2/1 题、功能交际 14 题 11.5%，**没发现数字错**。
- **能不能直接给教研用**：能。「易错点预警」表里的「样本题」现在是完整的小截图卡片（`ops-06e-full-report-4.png`），上一轮第 16 题被切掉一半，这次完整；Markdown 里 `[文字] ![图](…)` 没有包在反引号里了。
- **还有的毛病**：

### 1. 疑似重复的卷子，只有一个小标签在提醒，其他地方都像没事发生（严重，运营最容易误操作）
- **页面**：试卷库、审核页、确认弹窗、总览「最近导入」。（`ops-03e-library-after.png`、`ops-03h-dup-review.png`、`ops-03i-dup-confirm-dialog.png`、`ops-03l-overview-after-dup.png`）

- **希望怎么改**：状态栏直接写「疑似重复，未计入统计」（灰色）；审核页顶部放一条和 AI 备注同样醒目的横幅，带「确实是新卷」「删除这份」两个按钮；确认整份时如果它是疑似重复，弹窗里多一句「这份像是重复，确认后仍不会计入统计，要继续吗」；「最近导入」里给它一个同样的小标签。

### 2. 「我已核对」要我判断英语规则对不对，我判断不了，也没有「找谁」（中高）
- **页面**：报告 → 「我已核对」弹窗。（`ops-09c-boss-confirmed.png`）
