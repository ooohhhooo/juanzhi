## 一、在 Mac 上试用安装包（约 20 分钟）

安装包在项目的 `release/` 文件夹里：`/Volumes/Elements/Claude/english-exam-workbench/release/`。

| 文件 | 适用 | 大小 |
|---|---|---|
| `Juanzhi-1.2.0-mac-arm64.dmg` | Apple 芯片 Mac（M1/M2/M3/M4…），**你这台用这个** | 约 122 MB |
| `Juanzhi-1.2.0-mac-x64.dmg` | Intel Mac | 约 130 MB |
| `Juanzhi-1.2.0-win-x64-setup.exe` | Windows 安装版 | 约 116 MB |
| `Juanzhi-1.2.0-win-x64-portable.exe` | Windows 免安装版 | 约 105 MB |

**先注意一件事：** 打包版和之前的试用副本（`ewb-试用-M2`）用的是同一个数据目录：`~/Library/Application Support/english-exam-workbench/`。
- 打包版一打开，会把这里的数据库从 M2 时代的 v5 升级到 v10。
- 升级以后，再打开 M2 试用副本，它会提示「数据库版本高于程序版本，请升级应用」，用不了了。你在里面导入过的卷子都还在，打包版里能看到。
- 想留一份原样，打开打包版之前先把这个文件夹复制一份。

打开方式见 [安装指南](安装指南.md)。简单说：
1. 双击 dmg，把应用拖进「应用程序」。
2. 第一次打开会被系统拦住（因为没有付费签名）。到「系统设置 → 隐私与安全性」点「仍要打开」。

| # | 怎么做 | 应该看到 |
|---|---|---|
| 1 | 第一次打开 | 首次启动三步卡片：配置 AI（可跳过）、拖入卷子、选教材版本 |
| 2 | 点「加载示例数据」 | 12 份合成卷，多个年级、3 个以上学年。总览、看板（分布、同比、重难点、双向细目表）都有内容 |
| 3 | 把 `samples/` 里的 `g4-2025.pdf`、`g4-2025-page1.png` 拖进窗口 | 进入处理队列。PDF 走文字层，PNG 走 Mac 自带 OCR。没配 AI 时停在「待解析」 |
| 4 | 设置 → 知识点树：新建一个节点、改名、把它合并到另一个节点 | 看板数字随之变化；内置节点不能删除 |
| 5 | 设置 → 数据包：导出一个 `.ewb.zip` | 包里不含 AI 密钥，也不含示例数据 |
| 6 | 「清除示例数据」 | 示例卷全部消失，你自己导入的卷子不受影响 |
| 7 | 设置 → 关于、安装指南 | 版本 1.2.0；安装指南是完整正文 |
| 8 | 菜单栏 | 应用菜单是中文名「卷知」；Cmd+C、Cmd+V、Cmd+Q 好用（**还没有实机按过，请顺手试一下**） |

## 二、真实 DeepSeek 测试（等你操作）

1. 在应用里打开「设置 → AI 服务」，选 DeepSeek 预设，填入你的密钥，点「测试连接」。密钥只存在本机钥匙串里，不要发在聊天里。
2. 填好后告诉我。我会跑真实 AI 测试：
   - P1：解析两份样卷，核对分题和知识点标注的质量。
   - P2：同比分析。
   - P3：考情报告。
   - 统计费用。
3. 第一次用到密钥时，macOS 会弹窗询问是否允许访问钥匙串，选「始终允许」。因为没有付费签名，以后每次升级应用都会再问一次。

## 三、Windows（需要一台真实的 Windows 电脑）

按 [Windows验收清单](Windows验收清单.md) 一共 12 项，约 40 分钟。要带上两个 exe 和 `samples/` 里的三份样卷。

Windows 上目前**什么都没有实际运行过**：安装器、OCR 脚本、PDF 中文字体、关窗退出都只做了静态检查。这是现在最大的未验证项。

## 四、需要你决定的事

| # | 事项 | 现状 / 建议 |
|---|---|---|
| 1 | 推送 GitHub | 没推。推了以后 `.github/workflows/build.yml` 才会在云端 Windows 上自动构建和冒烟，这是不用 Windows 电脑也能验 Windows 的办法。工作流还从没运行过，第一次大概要调一下 |
| 2 | Mac 安装包分两个还是合成一个通用包 | 现在是 Apple 芯片、Intel 各一个。合成一个约 200 MB 以上，老师不用挑；改一行配置就行 |
| 3 | appId 和版权文字 | appId 现在是 `cn.edu.english-exam-workbench`，版权是占位文字。appId 发布后不宜再改 |
| 4 | 是否买签名证书 | 没买。Apple 每年 99 美元，能去掉「无法打开」提示和升级后的钥匙串再授权；Windows 证书能去掉 SmartScreen。不买的话，靠安装指南说明怎么打开 |
| 5 | 应用图标 | 现在是用代码生成的占位图标（蓝紫底、白色试卷加柱状图）。需要的话我让 Codex 画一个正式的，换上只要一张 1024×1024 PNG |
| 6 | `docs/screenshots/m5-smoke-report.pdf` 要不要留在仓库 | 约 600 KB，是导出 PDF 的样张 |
| 7 | 试用副本 `ewb-试用-M2` | 有了打包版就不需要它了。你同意的话我把它删掉（只删代码副本，不碰数据） |

## 五、已知缺口（不阻塞使用）

- **真实 AI 的输出质量未知**：P1 分题、P2、P3 都只用模拟 AI 测过。
- **Windows 全部未实机验证**：见第三节。
- **Mac 上没实走过的**：从浏览器下载的 dmg 走 Gatekeeper 放行的完整流程、Intel 真机、macOS 13 和 14。
- **审核页**：没有撤销，也不能「新增一道题」（M2 遗留）。题目跨行时截图框偏宽。
- **大数据包导入卡界面**：解包不能中途取消。数据库很大（GB 级）时，导入过程中界面会卡一阵；常规几百份卷子是秒级。
- **合并导入多出重复节点（小问题）**：仅限 M5 之前在知识点名里输入过 `|` 或换行的试用库，合并导入自己的数据包时会多出一个重复节点，不丢数据。
- **Windows 菜单栏是英文**：仍是 Electron 默认的英文菜单。
- **没有自动更新**：升级靠重新下载安装，数据会保留。

各里程碑的细节见 `docs/M1-交付说明.md` 到 `docs/M5-交付说明.md`，审核报告在 `docs/reviews/`。
