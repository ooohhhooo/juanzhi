## 一、方向约定

把下面这段原文放进渲染页 `index.html`，作为 `<body>` 第一个子节点的 HTML 注释。构建后，在产物里 grep `ba0d512d`，确认它还在。

```
THESIS: 每个考点都是一个词条——中文名做词头，下面是白话释义、斜体例句、考过几次、原卷例题；拒绝灰底蓝按钮的后台管理系统，也拒绝糖果色卡通教育风。
OWN-WORLD: 学习词典内页：冷白纸（#FBFCFD）、深墨蓝正文（#14213D）、词典蓝词头（#1F5FD1）、红色「易错」用法框（#D93A2B）、淡蓝信息框（#E8EDF5）；书口六色拇指索引对应六个知识大类；Source Sans 3 无衬线（含音标）+ 系统中文黑体；夜读版是深蓝封面布底。
```

## 二、为什么选这个

- **最核心的问题是看不懂术语。** 学习词典解决的就是这件事：每个词都配白话释义和例句。把「物主代词」做成词条「物主代词 *my / your / his* —— 表示『谁的』」，这本身就是功能，不是装饰。
- **使用者天天都在用词典。** 运营、辅导老师、家长都查过。词头、例句、「易混辨析」框、书口索引，都不需要另外学。
- **投屏要清楚。** 冷白纸配深墨蓝字，对比度高，投屏清楚。深色的夜读版适合晚上在家备课。

## 三、视觉系统

所有取值放在同一个来源 `src/renderer/design/tokens.ts`，同步到三个地方：CSS 变量、AntD `ConfigProvider` token、ECharts 主题。浅色和深色都要做，默认跟随系统，设置里可以手动切换。

### 1. 颜色

**基础色**

| 角色 | 浅色（词典内页） | 深色（夜读版） | 用途 |
|---|---|---|---|
| 纸 | `#FBFCFD` | `#0F1A33` | 窗口底色 |
| 内页 | `#FFFFFF` | `#16223F` | 面板、词条 |
| 正文墨 | `#14213D` | `#E9EEF7` | 正文 |
| 次要 | `#4B5873` | `#A9B4CC` | 说明、标签，对比度 ≥ 4.5:1 |
| 词头蓝 | `#1F5FD1` | `#7FA8FF` | 词头、当前导航、主按钮、链接 |
| 易错红 | `#D93A2B` | `#FF6B5E` | 只给易错、失败、需要处理的事项 |
| 信息框 | `#E8EDF5` | `#1D2B4D` | 「辨析」「提示」框的底色 |
| 细线 | `#D5DCE8` | `rgba(233,238,247,.16)` | 1px 分隔线 |

**拇指索引色**

每个知识大类一个颜色，全局固定，不能挪作他用。颜色取印刷油墨感，不用糖果色。

| 知识大类 | 浅色 | 深色 |
|---|---|---|
| 语音 | `#B7791F` 赭黄 | `#E2A94A` |
| 词汇 | `#2F8F5B` 绿 | `#5CC48A` |
| 语法 | `#1F5FD1` 词典蓝 | `#7FA8FF` |
| 交际 | `#0E8584` 青 | `#3EC1BF` |
| 阅读 | `#7A4FC4` 紫 | `#AE8CF0` |
| 写作 | `#B5482A` 砖红 | `#EE8466` |

**禁止**

- 渐变、玻璃拟态、发光效果。
- 灰底配蓝按钮的后台风。
- 米黄色纸配衬线标题的「AI 默认文艺风」。
- 颜色作为唯一的信息载体：旁边必须写字。

### 2. 字体

- **西文、数字、音标**：Source Sans 3，OFL 授权，含 IPA 音标字形。
  - 用 `@fontsource-variable/source-sans-3` 打包进应用，完全离线，正体和斜体都要。
  - 例句用斜体，词头用 700，正文用 400。
- **中文**：系统黑体栈 `"PingFang SC", "Microsoft YaHei", "Noto Sans CJK SC", "Source Han Sans SC", sans-serif`。不打包中文字体。
- **字号阶梯**：12 / 13 / 14（正文）/ 16 / 18 / 22 / 30 / 44。44 只用于总览的大字结论。
  - 词头 22–30px，加粗，词头蓝。
  - 投屏时正文不小于 14px。
- **例句**：斜体，目标词加粗，例如 *It's time **for** breakfast.*；中文意思用次要色跟在后面。
- **数字**：等宽数字 `tabular-nums`。
- **西文标签**：小型大写或 0.06em 字距。中文标签不加字距、不用斜体。

### 3. 版式和形状

- **版心**：正文最大宽度 1240px，居中。阅读类内容（报告、词条详情）每行约 68 个汉字。
- **两栏**：词条列表在宽屏时用两栏，栏间用 1px 细线分隔，像词典一样。
- **书眉**：每个分析页顶部一行小字，左边是范围（四年级 · 2025–2026 学年），右边是本页第一个和最后一个词条名。
- **面板**：1px 细线，圆角 8px，不加阴影。浮层（下拉、抽屉、对话框）才加阴影：
  - 浅色 `0 10px 28px rgba(20,33,61,.12)`
  - 深色 `0 10px 28px rgba(0,0,0,.4)`
- **按钮**
  - 主按钮：词头蓝实心，圆角 6px，文字 15px。
  - 次按钮：1px 墨色描边。
  - 危险操作：易错红描边。
  - 每个页面只放一个主按钮。
- **输入框**：1px 细线，聚焦时变成 2px 词头蓝。焦点环一律是 2px 词头蓝外描边。
- **不允许出现**
  - 卡片左侧粗色边条；
  - 一排同尺寸的「图标 + 标题 + 文字」卡片墙；
  - 标题上方的眉标签；
  - 01 / 02 / 03 装饰编号；
  - emoji 当图标；
  - 渐变文字；
  - 四个一模一样的大数字卡片。

### 4. 图标

- 用 `lucide-react`，线性，1.75px 描边，全局统一一套。
- 所有图标按钮都必须带文字。

## 四、标志性组件（放在 `src/renderer/design/`）

1. **`<Entry>` 词条，最核心的组件。** 从上到下：
   - 词头：中文考点名，词头蓝、加粗，后面跟斜体英文例词，例如「物主代词 *my · your · his*」。
   - 标签行：几个小型标签，例如 `考过 2/2 份`、`约 8 分`、`易错`（易错红）、`今年新考`、`样本不足`。每个标签悬停时显示白话解释。
   - 释义：① 一句白话，说清这个考点考什么。
   - 例句：斜体，目标词加粗，后面跟中文意思。
   - 原卷例题：「出自原卷」小标题，下面是原卷截图缩略图，点击放大，并写明是哪份卷子第几题。
   - 参见：→ 参见「be 动词一般疑问句」，可以点击跳转。
   - 词条有三种尺寸：紧凑（列表用）、标准（总览用）、完整（详情抽屉用）。
2. **`<UsageNote>` 用法框**，对应词典里的「易混辨析 / 注意」框。
   - 用于易错提醒、辨析（time for / time to）、样本不足提示、重复导入提醒、AI 失败。
   - 样式：1px 边框加信息框底色；左上角一个小标签，写「易错」「辨析」「注意」，易错用红色标签。
   - 不要用左侧粗色边条。
3. **`<ThumbIndex>` 书口拇指索引。**
   - 放在分析看板、总览、知识点相关页的右边缘，六个彩色竖向标签对应六个知识大类，每个标签显示中文名和考点数。
   - 点击后跳到该大类的词条组，或者按该大类筛选。
   - 当前项凸出 6px。
4. **`<Contents>` 目录导航**，替换现在的侧边栏。
   - 纯文字链接：总览、试卷库、处理队列、审核、分析看板、AI 报告；「设置」放在底部。
   - 当前页用词头蓝加粗，前面加一个小三角 ▸（用 SVG 画，不用字符）。
   - 待办数用小号数字跟在后面，例如「审核 · 3」。
   - 可以收起成只有图标加首字的窄栏，悬停时显示全名。
5. **`<GuideWords>` 书眉**：见上一节「版式和形状」。
6. **`<Glossary>` 术语释义。**
   - 界面上剩下的每个专业词都包一层，悬停显示词典式释义：词头、白话一句、例子一句。
   - 例：「分值占比：这类题占试卷总分多少。例：写作 30 分 / 总分 100 分 = 30%」。
   - 术语表集中放在 `src/shared/glossary.ts`，报告和界面共用。
7. **`<Headline>` 大字结论**：一句中文结论，句中关键数字用 44px Source Sans 3 Bold，例如「今年四年级 **72** 道题，最该补的是 **名词复数** 和 **time for / to**」。不要做成数字卡片。
8. **`<StatusLabel>` 状态标签**，用于处理队列和试卷库：小号描边标签，模仿词典的词性标签，比如「AI 解析中」「待审核」「已完成」「失败」；失败用易错红。AI 思考中显示「AI 正在思考 · 已用 48 秒（通常 2–3 分钟）」。

## 五、各页面怎么落

- **总览**：首屏照第一节的 FIRST VIEWPORT 做。首次打开时，在词条区域放三步引导，分两条路线：「我是运营」「我是辅导老师」。
- **试卷库**：表格做成词典「索引页」的样式：细线分隔、标题列加宽、等宽数字、操作按钮带文字。左侧学年和年级树改成词典目录的缩进样式。
- **处理队列**：一行一份卷子，用状态标签加预计时间。失败用用法框写清原因和怎么办，只给一个「重试」。
- **审核**：三栏结构不变（这是效率页）。
  - 左栏题目列表像词典的条目索引，已确认的打勾，需关注的用红色标签。
  - 中栏原卷保持白纸，深色模式下也是白纸，像书页放在深蓝布面上。
  - 右栏表单用新的视觉系统重做。知识点下拉的每一项显示「中文名 + 斜体例词 + 一句白话」，英文代码默认隐藏，管理员可以打开。
  - J / K / Enter 快捷键保留。
- **分析看板**：
  - **分布**：主视图是按拇指索引分组的词条列表，配一张横条图（条形用对应大类的颜色）。矩形树图保留为第二视图。
  - **同比**：「今年新考 / 今年没考 / 考得更多 / 考得更少」四组词条，用白话命名，不再写「基线 → 目标」。
  - **重难点**：词条排行，带易错用法框。
  - **知识点 × 题型表**：改成词典附录表的样式，热力用单一词头蓝的深浅。
- **AI 报告**：
  - 左侧是历史列表。
  - 生成前先选读者（老板 / 家长 / 老师 / 完整数据），每种读者用一种拇指索引色做标签。
  - 正文用阅读排版：版心约 68 字宽，原卷截图做成词条里的「出自原卷」样式。
  - 家长版给一个「复制到微信」按钮。
- **设置**：分成「常用」和「管理员设置」两组，技术项收进管理员设置。
- **导出 PDF**：浅色词典版，纸面干净；家长版不要密集表格。

## 六、动效

- 只有一个标志动效：点击拇指索引时，正文像翻到词典的某一节，横向滑入约 240ms，指数缓出。系统开启「减少动态效果」时直接切换，不做动画。
- 其他地方只有 150–200ms 的状态过渡。不要给每个区块都加同样的入场动画。

## 七、必须保留

- 所有现有功能和数据口径不变。
- 拖放导入、文件对话框、快捷键、键盘焦点样式都保留。
- 窗口最小宽度 1100px 时不能出现横向溢出。
- 深色、浅色两种模式逐页检查。
- AntD 组件可以继续用，但必须通过 token 和样式覆盖改成这套视觉，界面上不应再看出默认 AntD 的样子。

## 八、第二版修订（2026-10-26，用户看过第一版样张后提出）

用户原话：「侧边栏有点傻大……我觉得现在那个侧边栏做的太丑了，整个配色可以结合我给你发的那个参考，再结合你自己的想法，做一版。」

参考图：`.impeccable/refs/lms-1.jpg`，来自 Dribbble「LMS Dashboard - Student Analytics & Education UI/UX Case Study」。以下修订以用户给的参考为准，优先于本文件前面的冲突条款。

### 1. 外框改成「灰底 + 白色大画布」

- 应用底色改为浅灰，大约 `#ECECF1`。
- 主内容放在一块白色大画布上，圆角约 24px，四周留 16 到 20px 的灰边，看起来像浮在灰底上。
- 右侧可以留一条窄的工具栏，放搜索和小部件。用不用自己判断，不能挤压正文。

### 2. 侧边栏改成窄图标栏，不再是一整列文字

- 宽度约 76 到 84px，灰底，和画布分开。
- 顶部放产品徽标：用 SVG 画一个简洁的徽章，主色、线性风格，可以用打开的书或词典的意象，做得精致，不要卡通。
- 每一项是线性图标（主色），图标下面配两个字的小标签：总览、试卷、队列、审核、看板、报告。保留文字，是为了照顾不熟电脑的老师。
- 当前项：白色圆形或圆角方块底，带柔和阴影，图标用主色加深。
- 待办数用小号角标显示。
- 设置和外观切换放在底部。
- 收起功能不再需要。

### 3. 配色从「词典蓝」改为参考图里的长春花紫

| 角色 | 浅色 | 深色 |
|---|---|---|
| 主色 | `#5B57D1` 附近（长春花紫） | `#9C98FF` 附近 |
| 主色浅底 | `#EEEDFB` | `#26264A` |
| 正文墨 | `#1C1B2E` | `#ECEBF7` |
| 次要文字 | `#5E5D75` | `#A9A8C2` |
| 卡片描边 | `1px #1C1B2E` 低透明度，或 `#D9D8E6` | `rgba(236,235,247,.16)` |
| 易错 | `#E0445A`（玫红，呼应参考图里的品红点缀） | `#FF7A8C` |
| 底色 | `#ECECF1` | `#141427` |
| 画布 | `#FFFFFF` | `#1D1D35` |

- 六色拇指索引保留，但要和长春花紫协调：降低饱和度，统一明度，不能变成糖果色。
- 每个颜色的具体值由设计代理定，必须满足对比度要求（正文 ≥ 4.5:1）。

### 4. 卡片和按钮

- 卡片：白底，1px 细描边（参考图用的是深色细线），圆角 16 到 20px，不加阴影。
- 按钮：主色胶囊按钮（全圆角），小号次要操作也做成胶囊。
- 标签：胶囊形。

### 5. 字体

- 参考图用的是几何圆体（类似 Poppins）。
- 西文可以换成更圆润的几何无衬线，前提是 OFL 授权、能离线打包、带斜体，并且能显示例句里的音标；也可以继续用 Source Sans 3。由设计代理判断。
- 中文仍用系统黑体。

### 6. 保留的内容

词典方向的内容结构不变：词条、白话释义、斜体例句、出自原卷、易错用法框、书眉范围句、大字结论、拇指索引。这次只换外框、侧边栏、配色和形状，内容组织不动。

### 7. 不要照搬的地方

参考图里的这些不要照搬：
- 等距插画；
- 欢迎语；
- 天气、名言这类与业务无关的卡片；
- 一排一样的数字胶囊卡。

需要插画时，由协调会话另外安排 Codex 出图，这一版先不放。
