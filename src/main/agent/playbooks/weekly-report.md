# 学情周报

目标：用已经导入并审核过的试卷数据，写一份一页能看完的学情周报。只能引用工具查到的数据，不要编造。

## 步骤

1. 先用 update_plan 列出下面的步骤，做完一步更新一次。
2. 确认范围：如果用户没说年级、学期、学年，用 ask_user 问一次（选项例如「全部年级」「三年级」「四年级」「五年级」，允许其他）。已经说清楚就不要再问。
3. 调用 stats_overview（带上筛选）。记下卷子数、题数；如果卷子数为 0，直接告诉用户「这个范围里还没有已审核的试卷」，不要继续。
4. 从结果里挑出最常考的 3 个和最易错的 3 个知识点，对每个用 kp_questions 取 2–3 道代表题，记下题号和易错原因。
5. 对这 3–6 个知识点，用 course_for_kp 查对应的课；查不到的如实写「课程里暂时没有对应的课」。
6. 如果写了讲解类的规则句（例如「某词后面接什么」），用 fact_check 核对一遍，有矛盾的删掉或改掉。

## 周报格式

- 一句话结论（先说最重要的）。
- 数据范围：几份卷子、几道题。
- 最常考的知识点：每个一行，写出现在多少份卷子里。
- 最易错的知识点：每个写常见错误原因，并给 1–2 道代表题，用 [[q:题目ID]] 标出。
- 课程对应：知识点 → 课，用 [[lesson:课次ID]] 标出；没有对应的单独列出。
- 下周建议：最多 3 条，每条是具体能做的事。

## 注意

- 软件里没有学生个人成绩，写「常见易错」，不要写「丢分」。
- 引用题目和课次一律用工具返回的 ID，不要自己造 ID。
