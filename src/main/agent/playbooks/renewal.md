# 续费 / 续报分析

核心陷阱有三个：**分母定义不清**、**把结构变化当成真变化**、**把相关说成原因**。每一步都围绕这三点。

## 1. 先看数据概况，认列

用数据集概况工具看每张表，认出：

- **身份列**：学员编号（用来去重和跨表关联；姓名、手机号若已代号化就用代号）。
- **结果列**：是否续费 / 续报 / 退费 / 订单状态 / 续费金额 / 续费日期。取值可能是「是 / 否」「已续」「1 / 0」，也可能要靠「有没有下一期订单」推断——后者要用 run_query 自己构造。
- **到期信息**：课程结束日期 / 剩余课时 / 到期日。
- **维度列**：期次、班级、老师、校区、新老生、课程类型、渠道。
- **关联表**：满意度、到课、成绩（可选，用于找线索）。

## 2. 核对口径（最重要的一步，必须告诉用户你选了什么口径）

- **分母 = 到期的、有机会续费的人**，不是所有学员。还没到期的人不能算「没续费」。用 run_query 按到期日 / 课程是否结束圈出分母；圈不出时直接问用户。
- **分子 = 其中已续费的人**。如果「续费」要看有没有下一期订单，说明你用的时间窗口（例如到期后 30 天内）。
- 一个人多条记录（多门课、多次订单）：说明按「人」还是按「订单」算，默认按人，同一人只要续了一个就算续。
- 退费 / 转班 / 毕业：这些人要不要从分母里剔除，列出人数并让用户确认；默认毕业和已退费的不进分母，并写在口径说明里。
- 期次差异：不同期的到期规则不一样时不要硬合并。
- 缺失：结果列空的行不进分子也不进分母，报告人数。

## 3. 总体续费率

用 stat_ratio：分母条件 = 到期，分子条件 = 已续费，可加 groupKey。返回的结果带 95% 置信区间。分母小于 30 时直接说「人数少，区间很宽，仅供参考」。

## 4. 逐层拆分

- 用 stat_ratio 的 groupKey 或 stat_compare_groups（metric=rate）按维度逐个看；用 stat_find_low_groups（metric=rate）逐层找**明显偏低的小组**，维度只用数据里有的。
- 「样本小」的组只能提示，不下结论。
- 同时看**续费人数**和**续费率**：率低但人很少的组，影响不如率中等但人很多的组。

## 5. 和上期比：避免假变化

- 用 stat_period_compare（metric=rate），期次列指出本期和对比期，**一定带上 segmentKey**（新生 / 老生、课程类型、校区等数据里有的分层）。
- 看返回的 weighted：它把变化拆成「各层自己的真变化」和「人群结构变化带来的」。例如整体续费率降了，但按本期结构加权后其实各层都没降，只是新生占比变大了——要这样告诉用户。
- 同比（去年同期）和环比（上一期）分开说，不要混着写。

## 6. 关联原因（相关，不是因果）

按数据里有什么选用：

1. 满意度表：用 run_query 关联后，比较续费与未续费人群的满意度 / NPS（stat_compare_groups，分组列 = 是否续费）。
2. 到课表：续费与未续费人群的到课率、缺课次数、迟到次数。
3. 成绩 / 作业：续费前一段时间的成绩变化。
4. 退费原因、未续费原因等文字：用 text_classify 归类，再统计各类人数；引用 1–2 条原话。
5. 关联键对不上的行要说明丢了多少，不要悄悄忽略。
6. 表达方式：「没续费的人平均到课率低 12 个百分点」，不要写「因为缺课所以没续」。

## 7. 关键人群

- **犹豫人群**：满意度一般（中间分段）、到课有下滑但还没明确放弃的。用 stat_middle_segment 看这批人的特征，是最值得跟进的。
- **临近到期还没续的人**：用 run_query 列出（到期日在未来 N 天、尚未续费），按风险排序，可交给「学员跟进名单」剧本处理。

## 8. 结论与「这份数据说不清的地方」

- 结论带数字、分母和置信区间，不只给一个百分比。
- 说不清的地方至少想到：续费窗口是否已结束（数据截止日期之前刚到期的人可能还会续）；线下沟通、折扣等没有记录的因素；样本小的组；关联不上的人。

## 9. 口径说明

交付时附：分母分子的定义、时间窗口、剔除了哪些人、去重规则、样本小阈值（30）、显著性判断（p<0.05）。

## 10. 产出

- **看板章节建议**：总体续费率（带区间）→ 分层对比（标样本小）→ 偏低小组 → 与上期对比（真变化 vs 结构变化）→ 线索（满意度 / 到课）→ 待跟进名单。
- **名单**：临近到期未续费名单（代号 + 到期日 + 风险信号），可导出。
