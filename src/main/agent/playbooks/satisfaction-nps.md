# 满意度与推荐分分析

目标：回答「整体怎么样、哪里偏低、可能因为什么、先抓哪几个人群」。数据结构每家不同，**先认列再分析，不要假设有哪些列**。

## 1. 先看数据概况，认出每一列是什么

用数据集概况工具看列名、类型、取值分布、缺失比例，然后给每一列归类，并在回答里用一句话告诉用户你是怎么认的（认错了用户能纠正）：

- **分数列**：数字且范围固定（0–10 多半是推荐分；1–5 或 1–10 多半是满意度 / 评分）。一份问卷可能有好几个分数列，逐个确认含义。
- **维度列**：取值种类不多的文字或数字（年级、班级、老师、校区、期次、新老生、渠道）。取值几十上百种且基本不重复的（姓名、手机号）不是维度，是身份信息，不要拿来分组。
- **日期列**：提交时间、上课日期，可用来按期次 / 月份看趋势。
- **选项题**：取值是固定几个选项的文字；一个格子里有逗号 / 顿号分隔的多个取值是多选题。
- **文字题**：每条都不一样的长文字（意见、建议、原因）。

## 2. 核对口径（没核对前不要下结论）

用 run_query 查一遍并如实告诉用户：

- 有没有**重复提交**（同一个人 / 同一个编号多条）：有的话问用户按哪条算，默认保留最新一条并说明。
- **缺失**：分数列空了多少；空值不当 0 分，直接不计入。
- **期次 / 版本差异**：不同期的问卷题目、量表（5 分制和 10 分制）是否一样。量表不同不能直接合在一起比。
- **样本量**：总共多少人答了；回收率未知时不要说「代表所有学员」。

## 3. 总体

- 推荐分（0–10）用 stat_nps：给出 NPS、推荐者 / 中立者 / 贬损者占比、样本量。
- 满意度 / 评分用 stat_compare_groups 不分组的总体值，或 stat_distribution 看分布（均值会掩盖两极分化，同时给出各分数段占比）。
- 样本不足 30 人时直接写「样本只有 N 人，仅供参考」。

## 4. 逐层拆分（只用数据里真有的维度）

- 从粗到细排维度，例如 年级 → 班级 → 老师（有什么用什么，没有的不要编）。
- 先用 stat_compare_groups 逐个维度看，找「值明显不同」的维度；再用 stat_find_low_groups 传入 dimensions 逐层找**明显偏低的小组**。
- 同时有多期数据时，用 stat_period_compare 看变化；有新老生等分层时带上 segmentKey，避免把人群结构变化当成真变化。
- 工具返回「样本小」的组：只能说「人太少，看不出来」，不要因为它数值低就点名。
- 检验了很多组时，工具会提醒个别组可能是碰巧显著。看到「只有一个组显著、其余都不显著」时，措辞要克制。

## 5. 关联原因（相关不等于因果）

按数据里有什么选用：

1. **选项题**（如「不满意的方面」多选）：先用 stat_multi_choice 看各选项占作答人数的比例；再用 stat_option_impact 看选了某项的人分数比总体低多少。
2. **文字题**：用 text_classify 把意见归类（可以先让 AI 提类别，再让用户确认或修改类别后重跑），然后用 run_query 按归类列统计人数，再用 stat_option_impact（multi=true）看哪类意见对应的分数最低。引用时附 1–2 条原话例子（不含个人信息）。
3. **跨表关联**：如果数据集里还有到课、成绩、续费等表，且有可靠的关联键（学员编号等），可以用 run_query 关联后再看低分人群是否更常缺课、成绩更差。关联键对不上的行要说明丢了多少。
4. 表达方式固定为「选了 X 的人分数更低」「提到 X 的意见更多」，**不要写成「因为 X 所以分低」**。

## 6. 关键人群

- 中间分段最容易被忽略：推荐分 7–8 分（中立者）、满意度刚好一般的那档。用 stat_middle_segment 看占比，以及哪些特征（年级、老师、新老生等）在这批人里更集中。
- 这批人是最容易被争取、也最容易流失的，建议里要单独提一句。
- 贬损者（0–6 分）也用同样方法看特征，并列出文字意见的主要类别。

## 7. 结论与「这份数据说不清的地方」

结论写 3–5 条，每条带数字和样本量，格式：「现象 → 证据 → 可能的方向（标明是推测）」。再单独写一段「这份数据说不清的地方」，至少考虑：

- 答卷的人可能不能代表所有人（没回答的人可能更不满意）；
- 样本小的组、缺失多的列；
- 只有相关证据，没有证据证明原因；
- 缺少的信息（比如没有上课记录，就说不清低分和到课的关系）。

## 8. 口径说明

交付时附一小段：用了哪些列、怎么处理空值和重复、NPS 的分段方法、「样本小」的阈值（默认 30）、显著性怎么判（p<0.05）。

## 9. 产出

- **看板章节建议**：总体（NPS + 分布）→ 分层对比（柱状，标出样本小）→ 偏低小组清单 → 原因线索（选项占比 / 意见类别）→ 中间人群特征。
- **名单**：偏低小组的负责老师 / 班级清单；贬损者名单（如果问卷不匿名且用户需要跟进，只列编号或代号，不要把姓名手机号写进聊天正文）。
- 数据里有敏感列（已被代号化）时，一律用代号，不要尝试还原。
