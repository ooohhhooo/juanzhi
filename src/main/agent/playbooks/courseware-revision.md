# 课件修订对照

目标：教研拿「学校教材 + 学校试卷 + 本机构自己的大纲和课件」三方交叉对照，判断要不要穿插修改、更正自己的课件。结论和依据都来自工具，你只负责组织和说清楚，不要自己推算数字、教材位置或编例题。

## 步骤

1. 先用 update_plan 列出步骤，做完一步更新一次。
2. 定范围（缺的才问，用 ask_user，一次问清）：
   - 哪份机构大纲（A）；要不要拿另一份大纲（B）对比；
   - 对照哪几份教材（不说就用软件里已有的）；
   - 校内试卷范围（年级、学期、学年、考试类型，不说就是全部已审核的试卷）；
   - 每个知识点列几道校内例题（默认 3）。
   工具提示「没有找到」「匹配到多个」时，把现有名字列给用户选。
3. 调用 research_table 生成对照表（把用户说的范围写进参数）。它会把表存成产出，并写一份带格式的 Excel。看返回的汇总：几节课、几个知识点、几份课件、修订建议几条、教材有 A 没讲的知识点。
   - 返回「还没有把知识点对应到课」「需要重新匹配」时，告诉用户先去「课程」里做知识点匹配，不要继续。
4. 找出挂了课件的课（汇总里「课件：」那几行），逐节处理：
   - 用 lesson_kps 看这节的知识点、教材位置、校内原题和程序给的修订建议；
   - 用 courseware_read 读课件文字（长的分段读，够判断就行），对照知识点看课件到底讲了什么、用了什么例题。
   没挂课件的课：只能给「换例题」「要对齐」「可减」这类按大纲算出的建议，并说明「挂上课件后才能判断要补什么」，提醒用户在「课程 → 教研对照」里给这一节挂课件。
5. 逐节给修订建议，分四类，每条都要带依据：
   - 要补：学校常考或教材有、课件里没有的知识点或题型。依据写「校内 x/y 份卷子考过」「教材某册某单元（页码）」「课件里没有出现」。
   - 要对齐：课件和教材的单元顺序或说法不一致。依据写教材的册、单元，以及课件里的对应位置。
   - 换例题：建议用哪道校内原题做例题。依据写卷名、题号、是否易错、该知识点校内考过几份卷子。
   - 可减或超前：课件讲了，但教材和校内都没考。依据写「所选教材里没有对应单元」「校内 0/y 份卷子考过」；提醒这也可能是有意的拓展，由教研决定。
   程序已经给出的依据直接引用；你读课件后发现的补充（比如课件的例题说法和教材不一样），要写明出自哪一节的哪份课件。没有依据的建议不要写。
6. 把逐节建议存成表格：table_save 一张「课件修订建议」，列：课、类别、建议、依据。再用 output_export 导出 xlsx（需要用户同意）。
7. 写一份文档摘要：doc_create「课件修订摘要」，doc_write_section 依次写「一、结论」（三句话以内：几节课建议改、最要紧的三处）、「二、各节要改的地方」（按课，每条一行，带依据）、「三、这份数据说不清的地方」（知识点对应是 AI 匹配的结果需教研核对；较粗的教材位置；没挂课件的课；试卷份数少于 3 份不标常考）。
8. 最后告诉用户：对照表（Excel）、修订建议表、摘要文档都在右侧产出里；知识点对应请教研核对后再改课件。

## 规矩

- 数字、教材位置、卷名题号只写工具返回的，不要编。标「较粗」的位置只是大类对得上，要说明。
- 课件文字只在需要时读，不要把整份课件复述出来；不要写任何学员信息。
- 试卷范围里没有卷子时，直说「范围里没有可用的卷子」，不要编例题。
