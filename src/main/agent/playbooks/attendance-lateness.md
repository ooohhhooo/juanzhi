# 到课与迟到分析

各家考勤表的字段名和取值都不一样，**第一步不是算，而是弄清哪一列、哪个值代表「到了 / 迟到 / 缺课」**。认错了后面全错，所以要把认定写出来让用户确认。

## 1. 先看数据概况，识别出勤状态

用数据集概况工具看列名和取值分布。常见形态，按下面的线索识别：

| 形态 | 怎么认 | 举例 |
| --- | --- | --- |
| 状态列 | 取值种类很少的文字列，列名含 出勤 / 到课 / 状态 / 考勤 / 签到 | 取值「到、迟到、缺、请假」「出席 / 缺席」「1 / 0」 |
| 时间列 | 有「签到时间 / 进入时间 / 开始时间」和「计划上课时间」两类时间 | 迟到 = 签到时间晚于计划时间超过容忍分钟 |
| 时长列 | 「在线时长 / 听课时长」和「课程时长」 | 在线时长占课程时长很低 ≈ 迟到或早退 |
| 只有到的记录 | 没有缺课行，只有到了的人的签到 | 缺课要靠「名单 − 到课」用 run_query 推断，需有学员名单 |

识别规则：

- **到课**：状态取值像「到、出席、已到、正常、1」，或有签到时间。
- **迟到**：状态取值含「迟」；或签到时间晚于计划开始时间。**容忍分钟数（例如 5 分钟）要问用户或在口径里写明**，默认 5 分钟。
- **缺课**：状态含「缺、旷」；或名单里有但没有签到。
- **请假**：状态含「请假、假」。请假算不算缺课必须说明，默认**请假单列，不计入缺课，也不计入分母**，并在口径里写明。
- **补课 / 回放**：有这类取值时单列，不要和现场到课混在一起。

把你的识别结果写成一个小表（取值 → 到 / 迟到 / 缺课 / 请假 / 其他）发给用户确认，有不确定的取值（含义不明）必须问。

## 2. 核对口径

- **分母**：应到人次 = 排课 × 名单人数（请假按上面规则）。没有名单只有签到时，只能说「有签到记录的人次」，**算不出真实到课率**，要明说。
- **重复**：同一人同一节课多次签到，保留最早一条。
- **未开始 / 取消的课**：剔除，说明条数。
- **日期**：数据覆盖哪个时间段；周末 / 假期是否混入。
- **期次差异**：不同期考勤规则不同（有的期不记迟到）时分开看。
- 缺失：状态为空的人次不进分母，报告数量。

## 3. 总体

用 stat_ratio：分母 = 应到人次，分子 = 到课（或迟到，分别算一次）。得到到课率、迟到率和置信区间。分母小于 30 要提醒。

## 4. 逐层拆分（只用数据里有的维度）

- 用 stat_compare_groups（metric=rate）按班级、老师、课程、校区、星期几、时段、课次顺序（第几次课）逐个看。
- 用 stat_find_low_groups（metric=rate）逐层找**到课率明显偏低**的小组；迟到则把迟到作为指标，direction=high 找迟到偏多的小组。
- 「星期几 × 时段」用 stat_crosstab（agg=rate）做成热力表，看哪个时间段出勤差。
- 趋势：用 stat_period_compare 比较本期和上期，带 segmentKey（班级类型 / 新老生），避免结构变化造成假变化。
- 课次顺序：到课率随第几次课下降，常见于「越往后越不来」，用 stat_compare_groups 按课次分组观察。
- 「样本小」的组只提示。

## 5. 个人层面

- 用 run_query 算每个人的缺课次数、迟到次数、连续缺课次数。
- 这是「学员跟进名单」剧本的主要输入。到课异常的人列代号 + 次数，不下「不认真」之类的评语。

## 6. 关联线索（相关，不是因果）

- 到课与成绩 / 作业 / 满意度 / 续费有关联表时，关联后比较「缺课多」和「缺课少」的人群。
- 迟到集中在某个时段或某位老师时，只说「集中在」，不说「因为」；可以提出需要核实的假设（交通、课表冲突、提醒方式）。
- 请假原因若有文字，用 text_classify 归类后计数。

## 7. 关键人群

- **边缘出勤的人**：到课率在 60–80% 之间、还没到完全掉队的人，是最值得提前干预的。用 stat_middle_segment（分数列 = 个人到课率，min/max = 0.6–0.8）看其特征。
- **新近开始缺课的人**：近两次缺课、之前全勤。

## 8. 结论与「这份数据说不清的地方」

- 没有名单就没有真实到课率；
- 迟到容忍分钟数是假设；
- 线上课的签到未必等于真的在听；
- 请假的原因和是否补课；
- 样本小的班级。

## 9. 口径说明

交付时附：状态取值的认定表、容忍分钟数、请假与补课的处理、分母定义、去重规则、样本小阈值（30）。

## 10. 产出

- **看板章节建议**：总体到课率 / 迟到率 → 班级对比（标样本小）→ 时段热力表 → 课次趋势 → 个人异常名单。
- **名单**：连续缺课、迟到频繁的学员（代号、次数、最近一次），可导出。
