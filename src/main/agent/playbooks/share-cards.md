# 分享卡片

目标：做一张能直接发给学生或家长的竖版图片。一张卡只讲一个点，字要少。内容由你写，排版和图片由 card_make 完成。

## 步骤

1. 先用 update_plan 列出步骤，做完一步更新一次。
2. 判断给谁：给学生（audience=student）还是给家长（audience=parent）。用户没说清楚，用 ask_user 问一次。
3. 需要数据时先查，再写（学员的成绩、薄弱知识点、到课情况等）：用 list_datasets / dataset_profile / run_query 等查，每个数字都要来自查询结果，没有数据就不要编。给学生做单个知识点的卡不需要查数据。
4. 选版式 kind：
   - 学生：knowledge（知识点：词或要点对照 + 例句 + 易错提醒）、mnemonic（口诀：几行顺口溜 + 例句，可高亮关键词）、practice（小练习：2–4 道题 + 鼓励语）。
   - 家长：weekly（本周学情：指标 + 学了什么 / 做得好 / 要加强 + 家庭配合）、progress（阶段进步：前→后对比 + 一段话 + 下阶段预告）、brief（学习简报：01–04 分节）。
5. 写内容，注意每个字段有字数上限（card_make 的说明里有），写短、写准：
   - 学生卡：语气活泼、鼓励，像在跟孩子说话；一张卡只讲一个点；例句用学生熟悉的场景；易错提醒要具体（「不是 goed」）。
   - 家长卡：先说进步和做得好的，再说还要加强的；加强的地方给具体、家里 5 分钟能做的配合建议；不推销、不制造焦虑，不写「必须」「再不……就」这类话。
6. 调用 card_make（不用问选哪个模板，默认就行）。如果返回「内容太多」或有截断提示，精简后重做。
   - 老师想换模板 / 「按某个模板做」：先用 card_templates 找到那个模板的 templateId（老师说的名字、颜色、季节对上 name / scene），再用**同样的内容**调用 card_make 并写上 templateId。你完全可以做，不要说「做不了」，也不要让老师去找不存在的按钮。
   - 老师说「我选好了模板」但没说哪个：用默认模板（就是老师在「助手设置 → 分享卡片」里选的），card_templates 里标着默认的那个。
   - 也可以告诉老师：右侧产出面板里，卡片下面有「模板」下拉框，选一个就会用同样的文字立刻重画，不用再问你。
   - 版式是固定的：图片背景、颜色、字体都来自模板，你只写文字内容；文字太少会自动放大居中，太多会缩小，所以别为了「像模板」去改字段结构。
7. 告诉老师：卡片在右侧产出面板，请先预览一遍，没问题再点「复制图片」「保存图片」或「发到企业微信」。没有老师确认之前不要自己发出去。

## 隐私规则（程序也会检查，违反会被拒绝）

- 家长卡只能写这一个孩子的信息：不写其他孩子的名字，不写排名、不拿这个孩子和别的同学比，只和他自己的过去比。
- 孩子称呼默认只用名（程序会去掉姓；老师也可以在设置里选「不写名字」）。student 字段写代号即可。
- 任何卡片都不能出现手机号、学号、家庭住址。出现手机号会直接拒绝生成。
- 卡片里的学员信息写代号就行，程序在生成图片时换成真名。
