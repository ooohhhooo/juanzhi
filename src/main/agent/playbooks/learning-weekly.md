# 学情周报

适用于培训机构的班课，也适用于学校的班级（班主任、任课老师看成绩表和作业表）。**先认列再分析，不假设有哪些列**。

## 1. 先看数据概况，认列

先用 list_datasets 找到数据集，再用 dataset_profile 认出：

- **成绩列**：得分、百分比、等级（A/B/C）。满分不同的测验不能直接比分数，要先换算成得分率（得分 ÷ 满分），没有满分列就问用户。
- **作业列**：是否提交、提交时间、批改分、正确率。
- **时间列**：测验日期、作业日期、周次——用来划定「本周」和「上周」。
- **维度列**：年级、班级、老师、科目、知识点 / 题型、学生编号（姓名若已代号化就用代号）。
- **题目级数据**（若有）：每道题的得分，用于看薄弱知识点。

## 2. 核对口径

- **周的定义**：以周一到周日为一周，还是用户指定的日期范围；写进口径。
- **缺考 / 缺交**：不要当 0 分。成绩为空 = 没考，不进均值；作业没交要单独算「提交率」。
- **重复记录**：同一人同一次测验多条，保留最新一条并说明。
- **测验变化**：不同周的试卷难度不同，成绩均值变化可能是试卷难度造成的，不一定是学习变化。只有同一份试卷或同一班级对比同一次测验才能直接比较。
- **人数变化**：本周和上周参加的人不同时，要提示。

## 3. 本周总体

- 参考人数、均分（得分率）、中位数、最高最低：用 stat_distribution，并按分数段（edges 如 [0,60,80,90,100]，换算成得分率后）看分布。均值会掩盖两极分化，所以要同时给出分段占比。
- 作业：提交率（stat_ratio，分母 = 应交人数，分子 = 已交）、平均正确率。
- 样本不足 30 人时写「人数少，仅供参考」。

## 4. 逐层拆分

- 用 stat_compare_groups 按班级、老师、科目逐个看均分和提交率；用 stat_find_low_groups 逐层找**明显偏低**的小组（年级 → 班级 → 小组，只用数据里有的维度）。
- 班级之间比较时注意：班级人数少（<30）的只提示；入学基础本来就不同的班级，更适合比「进步」而不是比「分数」。
- 用 stat_crosstab（行 = 班级，列 = 分数段，agg=count，看每行占比）展示各班分布。

## 5. 和上周比

- 用 stat_period_compare 比较本周与上周（周期列 = 周次）；带 segmentKey（班级或基础层次）可以排除结构变化的影响。
- 同一批人的变化比整体均值的变化更可靠：对两周都参加的学员，用 run_query 算每人的得分率差，再看「进步 / 持平 / 退步」的人数。
- 变化要给显著性判断：工具会返回 p 值和白话说明，直接引用，**不要把不显著的小波动写成进步或退步**。

## 6. 进步与退步的人

- 退步：得分率比前几次均值低 10 个百分点以上（阈值用 stat_distribution 看全班波动后再定，告诉用户阈值）。
- 进步：同理。
- 只列有至少两次成绩的人；一次成绩的人没有「变化」可言。
- 名单只用代号，写出具体数字（「得分率 78% → 61%」）。需要联系的退步学员可以交给「学员跟进名单」剧本。

## 7. 薄弱点（有题目级或知识点数据时）

- 按知识点 / 题型汇总得分率，用 stat_compare_groups 找得分率**明显低于整体**的知识点，样本小的标注。
- 同时看班级 × 知识点（stat_crosstab，agg=mean 或 rate），区分「全体都弱」（教学上要讲）和「某个班弱」（可能该班进度或老师讲法不同）。
- 有错因文字（如「粗心」「概念不清」）时用 text_classify 归类后计数。

## 8. 关联线索（相关，不是因果）

- 提交率低的人是否成绩也低；到课差的人是否成绩差（有考勤表时关联）。
- 写成「作业提交率低于 60% 的学员，平均得分率比其余学员低 15 个百分点」，不要写成「不交作业导致成绩差」。

## 9. 结论与「这份数据说不清的地方」

结论 3–5 条，每条带数字和人数。说不清的地方：试卷难度差异、缺考的人、没有题目级数据所以说不清薄弱点、样本小的班级、数据只反映考试不反映课堂表现。

## 10. 口径说明

交付时附：周的定义、得分率换算方式、缺考缺交处理、去重规则、进步退步的阈值、样本小阈值（30）、显著性判断（p<0.05）。

## 11. 产出

- **周报结构建议**：一句话总览 → 本周数据（人数、均分、分布、提交率）→ 班级对比 → 进步与退步 → 薄弱点 → 下周关注点（每条对应一个班或一类学员）。
- **看板章节建议**（用 board_start、board_add_section、board_add_block 搭，board_preview 检查，board_export 导出）：分数分布 → 班级对比（标样本小）→ 与上周对比（带显著性）→ 薄弱知识点。
- **名单**：退步学员、作业未交学员（代号 + 具体数字），可导出。
