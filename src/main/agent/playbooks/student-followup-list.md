# 学员跟进名单

目标：给一线老师一份**可以直接拿去用的名单**——先联系谁、为什么、聊什么。信号只从数据里**真有的列**推断，没有的信号不编、不补。

## 1. 先看数据概况，盘点有哪些信号可用

先用 list_datasets 找到数据集，再用 dataset_profile 看所有表，列出能认出的信号来源（没有的明确告诉用户「这份数据里没有 X，所以名单没考虑它」）：

| 信号 | 从哪里来 | 怎么判断 |
| --- | --- | --- |
| 出勤下降 | 考勤 / 签到表 | 近 N 次课到课率明显低于之前；连续缺课；迟到变多（识别方法见「到课与迟到分析」剧本） |
| 成绩退步 | 成绩 / 测验 / 作业表 | 最近一次比前几次均值低；排名下降；作业提交率下降 |
| 低分 | 成绩表、满意度表 | 成绩低于班级下四分位（用 stat_distribution 算）；满意度低分、推荐分 0–6 |
| 犹豫意向 | 沟通记录、问卷意向列、跟进状态列 | 取值含「考虑、再看看、观望」，或文字备注经 text_classify 归为犹豫 / 价格顾虑 |
| 临近续费 | 订单 / 课时表 | 剩余课时少、到期日在未来 N 天且尚未续费 |
| 投诉 / 负面反馈 | 反馈表、文字备注 | 负面意见（text_classify 归类） |
| 久未联系 | 跟进记录表 | 距上次联系超过 N 天 |

## 2. 核对口径

- 用学员编号（或代号）把各表关联到「一人一行」；关联不上的人数要说明，不要悄悄丢。
- 去重、取最新状态；已退费 / 已毕业 / 已续费的人排除，并说明排除了多少。
- 统一「近期」的窗口（例如近 4 周）和「之前」的窗口，写进口径。
- 缺失：某个信号这个人没有数据，记「无数据」，**不当作正常也不当作异常**。

## 3. 构造信号

用 run_query 做出每人一行的宽表，每个信号一列（是否触发 + 具体数值），例如：近 4 周到课率、之前到课率、最近一次成绩与班级均值之差、剩余课时、距到期天数、上次联系天数。

文字类信号先用 text_classify 归类，再作为一列。

## 4. 给信号定权重，并用数据校准阈值

- 初始权重（可调整）：连续缺课 3、到课率下降≥20 个百分点 3、成绩退步 2、低分（班级下四分位）2、犹豫意向 3、临近到期未续费 3、负面反馈 3、久未联系 1。
- **阈值不要拍脑袋**：用 stat_distribution 看到课率、成绩、剩余课时的分布，用分位数定「明显偏低」，并把阈值告诉用户。
- 有历史续费 / 流失结果时，用 stat_compare_groups（metric=rate，分组 = 是否触发某信号）检验这个信号是否真的和流失相关；不相关或样本太小的信号降低权重并说明。
- 得分只用来排序，**不是概率**，不要写成「流失概率 70%」。

## 5. 排序与分层

- 总分从高到低；同分按距到期天数从近到远。
- 分三层：优先联系（多个强信号叠加）、本周关注（单个强信号）、保持观察。每层的人数要在合理范围，名单太长对老师没用：优先层默认不超过 20 人或班级人数的 15%，超出时提高阈值并说明。
- 只有一个弱信号的人不进名单。

## 6. 每人写原因和建议跟进点

每一行包含：学员代号 / 编号、班级、总分与层级、**触发的信号（带具体数据）**、**建议跟进点**。

- 原因要具体：「近 4 周到课 2/6，之前 6/6；上次测验比班级均值低 12 分」，不要写「出勤不好」。
- 跟进点按信号给方向，写成建议语气：
  - 出勤下降 → 先了解有没有时间冲突或家里情况，再看是否需要补课；
  - 成绩退步 → 看具体丢分的知识点（如有），给针对性的练习；
  - 犹豫意向 → 弄清顾虑是价格、效果还是时间，准备对应的回应；
  - 临近到期 → 提前沟通续期安排，先回顾孩子的进步再谈续费。
- 不写评价性的话（不认真、没希望），不猜测家庭情况。

## 7. 说清楚这份名单的局限（放在名单前面）

- 只用了哪些信号，没有哪些信号；
- 阈值和权重是什么，可以让老师调整；
- 名单是排序参考，不是判断；老师对学员的了解比数据多，请以老师判断为准；
- 有多少人因为关联不上或数据缺失没有被评估。

## 8. 口径说明

交付时附：关联键、窗口、排除规则、阈值、权重、样本小的班级（班级人数不足 30 时，班级内的比较仅作参考）。

## 9. 产出

- **名单**：按层级排序，字段为 代号、班级、层级、得分、触发信号、建议跟进点；**名单可导出**（交给导出功能生成表格，列名用中文）。个人信息按数据集的代号化规则处理，正文里不出现姓名手机号。
- **看板章节建议**（用 board_start、board_add_section、board_add_block 搭，board_preview 检查，board_export 导出）：名单概况（各层人数、各信号触发人数）→ 信号相关性（哪些信号真的和流失有关）→ 班级分布（哪个班优先层最多）。
- 回答里先给结论（优先联系几个人、集中在哪些班），再附前 10 人的摘要，完整名单走导出。
